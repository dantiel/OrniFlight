安全性

安全性

飛行前チェックリスト

  1. ウィング: ウィングがしっかりと取り付けられ、リンケージが損傷していないことを確認します。
  2. バッテリー: 完全に充電され、適切に固定され、正しいセル数
  3. コントロール: Configurator の受信タブでスティックの反応を確認します。
  4. フェールセーフ: 飛行前にベンチでテストします (フェールセーフ を参照)
  5. アーム スイッチ: スティック アーミングだけに依存しない — の設定とテスト
  6. 発射エリア: 人、障害物、頭上の障害物がないこと

腕の安全性

OrniFlight は、警戒する前に複数の安全装置を使用します。

  • スロットルが低い: スロットルは最小でなければなりません
  • レベル: クラフトは適度なレベルである必要があります
  • RX 信号: 有効な受信機信号が必要です
  • CPU 負荷: システムが過負荷になってはなりません
  • 校正: 加速度計とジャイロを校正する必要があります

機内の安全性

  • 目視可能な範囲内で飛行してください
  • 人や動物から安全な距離を保つ
  • 警告しきい値の前にバッテリー電圧 — を監視します
  • FPV: 常にスポッターと一緒に飛行します
  • 風: 羽ばたき飛行装置は風の影響を受けやすい可能性があります — 自分の限界を知ってください

緊急時の手順

状況 アクション
方向感覚の喪失 INDEPENDENT モードに切り替え、センタースティック
信号損失 フェールセーフは自動着陸します (LAND プロシージャが設定されている場合)。
翼の損傷 直ちに武装解除 — 翼を停止します。
バードストライク 武装を解除し、再武装する前にダメージを評価する
バッテリー残量低下 すぐに着陸します — 鳥飛行プターには自動回転がありません。

羽ばたき飛行装置特有のリスク

  • 挟み込みの危険: 翼の羽ばたきは怪我を引き起こす可能性があります — 武装しているときは手を離してください
  • リンケージの故障: 飛行前にすべてのプッシュロッドとボールジョイントをチェックしてください
  • Resonance: 特定の羽ばたき周波数は機体の共振を励起する可能性があります。回避するには — を調整して ONDAS スイープを行ってください。
  • グライド ロックアウト: 翼サーボが非中立位置で故障した場合、制御された着陸は不可能になります。— テスト サーボ フェールセーフ位置
