# フライトモード

モードは送信機のAUXスイッチで切り替えます。各モードは、OrniFlight コンフィギュレーターの **モード** タブで特定の AUX チャンネル範囲に割り当てることができます。

## 標準モード

|モード |機能 |
|------|----------|
| **ARM** |飛行制御を有効にする (モーター/サーボがアクティブ) |
| **ANGLE** |自動レベル — クラフトはスティックを中心に置くとレベルに戻ります |
| **HORIZON** |ハイブリッド — 角度モードは中心付近、フルスティックではアクロ |
| **ACRO** |デフォルト — 自動レベルなし、純粋なレート制御 |
| **AIRMODE** |フル権限を得るために、PID ループをゼロ スロットルでアクティブに保ちます。

## OrniFlight 固有のモード

| ID |モード |機能 |
|----|------|----------|
| 50 | **INDEPENDENT** |独立した翼制御 — 各翼は独自のサーボ チャネルに応答します。
| 51 | **GLIDE** |グライド モード — 翼は水平位置にロックされ、ソアリングを実現 |
| 52 | **PROFILE** |フライト プロファイルの選択 — 3 つの PID/ONDAS プロファイル間で切り替え |

## ユーティリティモード

|モード |機能 |
|------|----------|
| **BEEPER** |失われた航空機を見つけるためにブザーを作動させる |
| **BLACKBOX** | Blackbox ログの開始/停止 |
| **FAILSAFE** |フェールセーフ ステージ 2 (パニック スイッチ) を手動でトリガーする |
| **OSD** | OSD の表示を切り替える |
| **TELEMETRY** |テレメトリ出力を有効/無効にする |

## 羽ばたき台のメモ

- **INDEPENDENT** モードは OrniFlight — に固有であり、非対称推力と差動翼制御のための翼ごとのサーボ マッピングが可能になります。
- **GLIDE** モードは翼を中立位置に保持し、熱上昇やエネルギー効率の高い降下に役立ちます
- **PROFILE** スイッチにより、さまざまな飛行条件 (例: 巡航と積極的な操縦) に合わせて飛行中に ONDAS パラメーターを変更できます。
