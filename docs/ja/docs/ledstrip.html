LED ストリップ

OrniFlight は、ステータス表示と視覚的フィードバックのためのアドレス指定可能な WS2812/SK6812 LED ストリップをサポートします。

構成

LED ストリップは、OrniFlight コンフィギュレーターの LED ストリップ タブで設定されます。各LEDの位置、色、機能を個別に設定できます。

関数

機能 視覚効果
バッテリーインジケーター 緑→黄色→赤からの色のグラデーション
RSSI 信号強度表示
アームの状態 腕の色の変更/武装解除
フライトモード モード固有の色
警告 バッテリー残量低下時の点滅パターン、フェイルセーフ
フラッピングインジケータ 現在のフラッピング周波数でのパルス
スラスト方向 ロール/ピッチ/ヨー出力を示すカラーシフト
GPS 衛星ロックとホーム方向

ハードウェア

  • WS2812 または SK6812 RGB LED
  • フライト コントローラーの LED パッド/ピンに接続します
  • BEC からの LED の電源 (3.3V — からの電力供給は行わないでください。5V を使用します)
  • 長いストリップ (LED が 8 つを超える) の場合は、FC を介さずに、5V 電源をバッテリー パッドに直接接続します。

羽ばたき飛行装置の使用

羽ばたきインジケーターは、OrniFlight — LED が翼のストローク周波数と同期してパルスする独自のもので、羽ばたきのリズムを視覚的に表現し、ONDAS のリズム パラメーターの調整に役立ちます。
