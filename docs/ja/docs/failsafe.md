# フェイルセーフ

OrniFlight には、受信機の信号損失が発生した場合に羽ばたき飛行装置を保護する 2 段階のフェイルセーフ システムが搭載されています。

## 2 段階システム

### ステージ 1 — 信号損失が検出されました

次の場合にトリガーされます:
- いずれかの飛行チャネルに無効なパルス長があります
- 受信機はフェールセーフ モードを報告します
- 設定された期間、受信機から信号がありません

**アクション**: すべてのチャネルがフォールバック値 (`rxfail` で設定) に切り替わります。信号が戻ると、短い回復ウィンドウが — 始まり、通常の飛行が再開されます。

### ステージ 2 — ガードタイムが終了しました

ステージ 1 が `failsafe_delay` (デフォルト: 400ms) より長く持続し、かつクラフトが武装している場合に開始されます。

**手順** (`failsafe_procedure` 経由で設定可能):

|手順 |行動 |
|----------|----------|
| **DROP** |直ちに武装解除 — 翼が停止し、航空機が降下します。
| **LAND** |グライド モード — 翼は水平にロックされ、制御された降下 |

**LAND** は、鳥飛行プター — に推奨される手順です。滑空降下のために翼を中立位置に保持し、信号回復のための時間を与えます。

## CLI 設定

```
set failsafe_delay = 4         # Guard time in 0.1s (4 = 400ms)
set failsafe_procedure = LAND  # DROP or LAND
set failsafe_throttle = 1000   # Fallback throttle (low)
set failsafe_switch_mode = STAGE1  # Transmitter switch behavior
```

## 受信機のフェールセーフ

また、信号損失時に**パルスなし**を出力するように受信機のフェールセーフを設定します。これにより、フライト コントローラーが損失を検出し、ステージ 1 をアクティブ化できるようになります。

## テスト

**翼リンケージを外した状態で**ベンチ上でフェールセーフをテストします。
1. FAILSAFE モードをスイッチに割り当てます
2. 宇宙船の準備を整える
3. スイッチ → を切り替えて、フェールセーフ手順を確認します。
4. サーボの動作が期待どおりであることを確認します。
