# テレメトリ

テレメトリは、OrniFlight から無線送信機 — のバッテリー電圧、電流、RSSI、GPS の座標、高度などの飛行データを送信します。

## サポートされているプロトコル

|プロトコル |無線システム |ワイヤー数 |
|----------|---------------|---------------|
| **CRSF** |クロスファイア / トレーサー / ELRS | RX と統合 (双方向) |
| **SmartPort** | FrSky | 1 ワイヤー (TX ピン) |
| **HoTT** |グラウプナー | 1 ワイヤー (TX+TZ) |
| **IBUS** | FlySky | 1 ワイヤー (センサー TX) |
| **LTM** |光テレメトリ (MWP) | 1 ワイヤー (TX) |

## 構成

1. コンフィギュレーター → **ポート** で、UART TX ピンを適切なテレメトリ プロトコルに設定します。
2. テレメトリ機能を有効にします: `feature TELEMETRY`
3. 必要に応じてテレメトリ反転を構成します

**CRSF** の場合、テレメトリは自動的に処理されます。— 個別のポートは必要ありません。

## SmartPort (FrSky)

SmartPort では、F4 プロセッサで信号の反転が必要です。次のいずれか:
- インバーター内蔵フライトコントローラーを使用
- SoftSerial を `set tlm_inversion = ON` とともに使用する

```
feature TELEMETRY
set tlm_inverted = ON
set tlm_halfduplex = ON
```

## テレメトリ データ

OrniFlight は次のように送信します。
- VBAT 電圧 (メインバッテリー)
- 消費電流 / 消費 mAh
- RSSI (信号強度)
- フライトモード/アームステータス
- GPS 座標 (装備されている場合)
- 高度 / バリオ (気圧計の場合)
- ONDAS フライト プロファイルがアクティブです
