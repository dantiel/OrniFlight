シリアルポート数

OrniFlight は、周辺機器との通信にシリアル ポートを使用します: レシーバー、GPS、テレメトリ、VTX コントロール、ブラックボックス ログ、および MSP (コンフィギュレーター接続)。

## シリアルポートの種類

|タイプ |説明 |最適な用途 |
|------|-----------|----------|
| **VCP** | USB 仮想 COM ポート — プロセッサへの直接 USB 接続 |コンフィギュレーター (MSP) |
| **UART** |ハードウェア信号検出付きハードウェア TX/RX ピン | RX、GPS、テレメトリ、VTX、ブラックボックス |
| **SoftSerial** |任意のピン ペアでソフトウェア駆動のシリアル |低帯域幅: テレメトリのみ |

VCP は物理的な UART — を消費せず、コンフィギュレーターで常に使用できます。

## ポートの割り当て

OrniFlight Configurator で、[**ポート**] タブに移動して機能を割り当てます。

|機能 |典型的なUART |メモ |
|----------|---------------|----------|
|シリアルRX | UART1 または UART3 | SBUS、CRSF、IBUS など |
| GPS | UART3 または UART6 | 57600 または 115200 ボー |
|テレメトリー |任意の TX ピン | SmartPort、HoTT、IBUS |
| VTX (トランプ/SmartAudio) |任意の TX ピン |単線 |
|ブラックボックス |任意の TX ピン | OpenLog またはオンボードフラッシュ |
| MSP | VCP (USB) |コンフィギュレータ接続 |

## OMNIBUSF4 ポートマッピング

| UART |ピン |一般的な使用法 |
|------|------|-----------|
| VCP | USB | MSP (コンフィギュレーター) |
| UART1 | TX1/RX1 |シリアルRX |
| UART3 | TX3/RX3 | GPS またはテレメトリ |
| UART6 | TX6/RX6 |無料 / ブラックボックス / VTX |

## SoftSerial

SoftSerial は利用可能ですが、帯域幅が限られています。低レートのテレメトリ (例: 9600 ボー SmartPort) にのみ適しています。シリアル RX または GPS には推奨されません。
