# ブザー

OrniFlight は、可聴ステータス表示と紛失したモデルの位置を示すアクティブ ブザーをサポートしています。

## 関数

- **武装/武装解除** — 独特のトーン
- **バッテリー残量低下** — という警告音が繰り返し鳴ります
- **フェールセーフ** — SOS パターン
- **紛失モデル** スイッチ経由で — 連続ビープ音が鳴る
- **GPS 修正** 衛星ロック時の — 確認音
- **キャリブレーション** ジャイロ/アクセルキャリブレーション中の — ビープ音パターン
- **RX 信号損失** レシーバーの接続が切断された場合の — 警告

## ハードウェア

- 5V アクティブ ブザー (パッシブ ピエゾではありません) を **BUZZ-** および **BUZZ+** パッドに接続します。
- ブザーは FC — のトランジスタによって駆動され、標準ブザーに外部ドライバーは必要ありません

## CLI 設定

```
beeper -GYRO_CALIBRATED     # Disable gyro calibration beeps
beeper -RX_LOST             # Enable receiver lost warning
beeper -ON_USB              # Disable beeper when USB connected
```

## 羽ばたき飛行装置の安全性

ブザーは、背の高い草や葉に着陸する可能性のある大型の羽ばたき飛行装置に特に役立ちます。必要なときにすぐに起動できるように、モーメンタリー スイッチで BEEPER モードを設定します。
