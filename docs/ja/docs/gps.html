GPS

GPS は、鳥飛行プターの位置保持、ホームへの復帰、テレメトリベースのナビゲーションを可能にします。 OrniFlight の GPS 機能は機能しますが、実験的なものと考えられています — は常に視界内で飛行します。

サポートされているプロトコル

  • UBLOX (推奨) — UBlox バイナリ プロトコル、効率的で信頼性の高い
  • NMEA — テキストベースの標準プロトコル

ハードウェア

  • BN-880、BN-220、または類似の UBlox M8N GPS+Compass モジュール
  • 接続: TX/RX を空きの UART に加えて 5V/GND に接続
  • 干渉を最小限に抑えるために、GPS を電源線やサーボケーブルから離して取り付けます。
  • コンパス/磁力計は磁気源 (電源線、サーボ) から離す必要があります。

構成

feature GPS set gps_provider = UBLOX set gps_sbas_mode = AUTO set gps_auto_baud = ON set gps_ublox_use_galileo = ON

  1. ポート タブでシリアル ポートを GPS に割り当てます (UBlox のデフォルトは 115200 ボー) 2.GPS機能を有効にする 3.プロバイダーの設定
  2. 保存して再起動します

OSD 要素

OSD に表示される GPS データには次のものが含まれます。 - 衛星数と修正タイプ - GPS 座標 (緯度/経度) - 対地速度 - 高度 (GPS) - 家からの距離 - ホーム方向矢印

羽ばたき飛行装置に関する考慮事項

  • GPS アンテナは空がきれいに見える必要があります — 取り付け位置は羽ばたきの場合に重要です
  • 小型羽ばたき飛行装置では重量ペナルティが大きくなる
  • GPS 支援の RTH (ホームへ戻る) では、羽ばたき飛行ダイナミクスのナビゲーション PID 値を慎重に調整する必要があります
