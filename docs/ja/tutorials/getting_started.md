# はじめに

OrniFlightへようこそ！このガイドでは、鳥飛行装置フライト コントローラーの初期セットアップについて説明します。

## 必要なもの

- **OrniFlight コンフィギュレーター** — [orniflight.org](https://orniflight.org) からダウンロード
- **USB ケーブル** — フライトコントローラーをコンピューターに接続します
- **羽ばたき飛行装置**:
  - サポートされているフライト コントローラー (OMNIBUSF4、TINYFISH)
  - 翼作動用サーボ
  - 送信機にバインドされた受信機
  - バッテリー (2S–4S LiPo)

## クイックスタート

### 1. フラッシュファームウェア

1. **OrniFlight コンフィギュレーター** を開きます
2. **ファームウェア フラッシャー** タブに移動します
3. ボードターゲットを選択します (OMNIBUSF4 または TINYFISH)
4. 最新の安定バージョンを選択します
5. [**ファームウェアのロード**]、[**ファームウェアのフラッシュ**] の順にクリックします。

### 2. 初期構成

フラッシュ後、コンフィグレータはカスタムデフォルトを適用するように求めます。 **いつでも受け入れます。**

### 3. 受信機のセットアップ

1. **ポート** タブ → に移動し、正しい UART を `Serial RX` に設定します。
2. **設定** タブに移動します → 受信機プロトコル (CRSF、SBUS など) を選択します
3. **受信機** タブ → に移動し、スティックの動きが予想されるチャンネルと一致していることを確認します。
4. チャネルエンドポイントを設定します: 1000–2000、1500 センター

### 4. サーボのセットアップ

1. **サーボ** タブに移動します
2. サーボマッピングが羽ばたき飛行装置の翼構成と一致していることを確認します。
3. 必要に応じて、サーボの方向 — 逆をテストします。
4. 中心位置を設定します (翼の水平 = 1500)

### 5. モードのセットアップ

1. **モード** タブに移動します
2. ARM を AUX スイッチに割り当てます
3. 必要に応じてフライトモード (ANGLE / ACRO / HORIZON) を割り当てます。
4. INDEPENDENT と GLIDE を予備スイッチに割り当てます
5. 失われたモデルを見つけるために BEEPER を構成します

### 6. 初飛行

1. **ベンチテストのために翼リンケージを取り外します**
2. サーボの動作方向を調整して確認します。
3. スロットル応答を確認する
4. 最初の実際のフライトの場合: ANGLE モード、低レートを使用します。
5.目の高さにホバーし、必要に応じてトリミングします
