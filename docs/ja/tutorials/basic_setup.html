基本的なセットアップ

基本的なセットアップ

最初の飛行用に羽ばたき飛行装置を設定します。

飛行前チェックリスト

何よりもまず:

  • [ ] フライト コントローラーが OrniFlight で点滅しました
  • [ ] レシーバーがトランスミッターにバインドされています
  • [ ] サーボは正しい PWM 出力に接続されています
  • [ ] バッテリーが接続されました (翼は固定されました!)

受信機のセットアップ

CRSF (推奨)

  1. [ポート]タブ: UART (例: UART1) を「シリアル RX」に設定します。
  2. [構成] タブ: レシーバー モード = 「シリアルベース レシーバー」、プロバイダー = 「CRSF」
  3. 電源を入れ直し、「受信機」タブでチャンネル入力が移動することを確認します。

SBUS / その他

同じプロセス — で [構成] タブで適切なプロトコルを選択します。

サーボマッピング

「サーボ」タブ:

サーボ 機能 デフォルト率
サーボ0 左翼 250Hz
サーボ 1 右翼 250Hz
サーボ2 クレスト/ラダー 50Hz

サーボの範囲に合わせて最小/最大/中間を調整します。 「オーバーライド」でテストして方向を確認します。

フライトモードの選択

[モード]タブ:

  1. ARM: スイッチに割り当てます (安全!)
  2. ORNITHOPTER INDEPENDENT または ORNITHOPTER GLIDE: 主要な飛行モードを選択します
  3. ORNITHOPTER PROFILE: 飛行中のプロファイル切り替え用のオプションの — 割り当て

ONDAS 初めてのチューニング

[詳細] → ONDAS サブタブに移動します。

  1. Cadence ゲイン: 50 (中間) から開始します。これは最も重要なパラメータです。
  2. Ferocity D ゲイン: 30 から開始します。これが主な安定化です。
  3. Ferocity P ゲイン: ロール/ピッチの場合は 20、ヨーの場合は 0 から開始します。
  4. Balance ゲイン: 0 (中央)。

バッテリーを接続し、羽ばたき飛行装置をしっかりと固定して、ARM。サーボの動きを観察してください。— 滑らかな正弦波状の羽ばたきが見られるはずです。

初飛行

  1. 風に向かって軽く投げることから始めます 2.GLIDEモードを使用すると自然な上昇感が得られます
  2. 周波数を直接制御したい場合は、INDEPENDENT モードを使用します。
  3. 着陸、ONDASを調整し、繰り返します
