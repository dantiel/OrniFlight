# ONDAS チューニングガイド

> *各パラメーターを感覚でチューニングする方法 ONDAS 理論 — の実践的な相棒*。

## チューニング順序

ONDAS パラメータは相互依存しています。次の順序で調整します。

```
1. Cadence    →  timing
2. Ferocity D →  primary stabilization
3. Ferocity P →  response crispness
4. Balance    →  upstroke/downstroke bias
5. Warp       →  modulation width
6. Anchor     →  dry/wet mix
7. Resonance  →  cycle-to-cycle memory
8. Phase 2    →  advanced (prescience, espelho, saudade, SSFF)
```

## ステップバイステップ

### 1. Cadence — フェーズ ウィンドウを見つける

**目標**: モジュレーションを翼の噛みつきが最も多い場所に配置します。

**方法**: 
- 50歳からスタート
- 70 — に増やすとロール応答が弱くなりませんか?
- 30 — に減らすとロール応答が強くなりますか?
- 「最強」ポイントは、翼のパワーストロークがピークに達する場所です

**高すぎる兆候**: 反応が鈍く、機体が「遅れている」ように感じる
**低すぎる兆候**: ぎくしゃくした応答、ロール時のオーバーシュート

### 2. Ferocity D — 着実に作業を進める

**目標**: 発振のない一次安定化。

**方法**:
- 20時に開始
- ホバリングまたは定常前進飛行
- クラフトが「硬くなった」と感じるまで増やします。
- 最初に発振に気づいた場所から 5 ポイント後退します

**高すぎる兆候**: 細かい振動、サーボのモーターのようなノイズ
**低すぎる兆候**: クラフトがドリフトする、緩む感じがする

### 3. Ferocity P — サクサク感

**目標**: 反応性はありますが、ぴくぴくしません。

**方法**:
- 15時に開始
- ロールスティックをぶつけてください — クラフトはすぐに噛みつきますか？
- スティックの反応が鮮明になるまで増やします
- オーバーシュートが発生した場合は後退してください

**高すぎる兆候**: スティック入力後の呼び出し音、跳ね返り
**低すぎる兆候**: 鈍くて反応が遅い

### 4. Balance — 非対称チューニング

**目標**: 双方向で同等の権限。

**方法**:
- まっすぐに水平に飛行します
- 左ロール、応答速度に注意
- 右ロール、応答速度に注意
- バランスを調整して均等化します

### 5–7。 Warp、Anchor、Resonance

パラメーターを微調整します。 1 ～ 4 が固まってから調整してください。

|パラム |開始 |調整時期 |
|----------|----------|---------------|
| Warp | 50 |モジュレーションが広がりすぎる、またはピーキーすぎるように感じます。
| Anchor | 70 |生の PID をもっと多くまたは少なく混ぜてほしい |
| Resonance | 30 |ホバリングが不安定、または前進飛行中に音が鳴る感じがする |

### 8. Phase 2 — 上級

|パラム |効果 |
|------|----------|
| Prescience |タイミング アドバンス — が高い = 変調の位相がさらに進む |
| Espelho |差動カップリング — のロールがきつくなり、効率が低下する可能性があります。
| Saudade |ストロークメモリ — はスムーズですが、応答性は低くなります。
| SSFF |直接ジャイロ→波噴射— 10時スタート |
