# 지원되는 하드웨어

OrniFlight는 상용 STM32F3/F4/F7 비행 컨트롤러에서 실행됩니다. 기준선은 **STM32F3** —입니다. 서보 가능 타이머 핀이 있는 모든 F3 대상은 날아갑니다.

## 비행 컨트롤러

| 보드 | MCU | IMU | 플래시 | 수신기 | 상태 |
|-------|------|------|-------|----------|---------|
| **TINYFISH** | STM32F303 | MPU6000(SPI) | 256 KB | FrSky D8(통합) | ✅ 기본 |
| **OMNIBUSF4** | STM32F405 | MPU6000(SPI) | 1 MB + 16 MB SPI | — | ✅ 지원됨 |

### TINYFISH — 가장 가벼운 OrniFlight 타겟

fishpepper가 설계한 TINYFISH는 페더급 F3 기반의 이상적인 ornithopter 비행 컨트롤러이며 **통합 FrSky D8 수신기**를 탑재하고 있습니다. 외부 RX 없음, 추가 배선 없음 — 전원, 서보 및 비행만 가능합니다.

- **MCU**: STM32F303CCT6 @ 72MHz
- **자이로**: MPU6000(SPI, 8kHz 가능)
- **플래시**: 256 KB 온칩
- **RAM**: 40 KB
- **수신기**: 통합 FrSky D8(SBUS는 내부적으로 UART2로 라우팅됨)
- **UART**: VCP + 2개의 하드웨어 UART(GPS/CRSF 추가 기능의 경우 UART1는 무료)
- **입력**: 2-4S LiPo (직접 서보 전원)
- **무게**: ~2.5g

TINYFISH는 탁월한 플랩핑 제어에 F7가 필요하지 않음을 증명합니다. STM32F303는 전체 ONDAS 파이프라인 — 10개의 변조 채널, 사다리꼴 날개 ODE, 256 KB 내에서 4개의 비행 프로필 —를 실행합니다.

### OMNIBUSF4 — 접근 가능한 일꾼

전형적인 F4 타겟입니다. 저렴하고 유비쿼터스적이며 OSD 및 블랙박스 로깅을 위한 충분한 SPI 플래시를 갖춘 모든 기능을 갖추고 있습니다. 개발 및 대규모 빌드를 위한 선택입니다.

- **MCU**: STM32F405RGT6 @ 168MHz
- **자이로**: MPU6000(SPI, 8kHz 가능)
- **플래시**: 온칩 1 MB + 16 MB SPI (블랙박스)
- **RAM**: 192 KB
- **OSD**: AT7456E (MAX7456와 호환 가능)
- **UART**: VCP + 5개의 하드웨어 UART
- **기압계**: BMP280(일부 변형)
- **입력**: 2-6S LiPo

## 오니톱터 해부학

### 윙 서보

OrniFlight는 PWM 서보를 통해 날개짓을 제어합니다. 주요 사양:

| 매개변수 | 일반적인 범위 |
|------------|---------------|
| 펄스 폭 | 500–2500 µs |
| 센터 | 1500 µs |
| 빈도 | 50–330Hz |
| 스트로크 각도 | ±15–45° |

고성능 오니톱터의 경우 업데이트 속도가 330Hz인 디지털 서보를 권장합니다. 아날로그 서보는 50Hz에서 작동하지만 정밀도가 낮습니다.

### 수신기

모든 직렬 수신기 프로토콜이 지원됩니다. CRSF(TBS Crossfire / ExpressLRS)는 다음에 권장됩니다.
- 낮은 대기 시간(플래핑 제어에 중요)
- 내장 원격 측정
- 프로토콜을 통한 RSSI(추가 배선 없음)

### 배터리

- **2S(7.4V)**: 소형 오니톱터, 직접 서보 전원 공급
- **3S(11.1V)**: 중형 오니톱터, BEC는 서보에 필요합니다.
- **4S(14.8V)**: 대형 오니톱터, 외부 BEC 권장

## 지원되는 주변기기

| 주변기기 | |를 통해 | 메모 |
|------------|------|-------|
| GPS | UART | UBlox M8N 또는 호환 가능 |
| VTX | UART TX | 부랑자, SmartAudio |
| 카메라 | — | 모든 아날로그 FPV 카메라 |
| 부저 | BUZZ 패드 | 활성 5V 부저 |
| LED 스트립 | LED 패드 | WS2812 / SK6812 |
| OpenLog | UART TX | 블랙박스 로깅 |
| 블루투스 | UART | 모바일 튜닝을 위한 MSP 패스스루 |

## 미래 목표

OrniFlight는 플래핑 서보 제어에 충분한 UART 및 타이머 리소스를 사용할 수 있는 추가 STM32F4/F7 대상을 지원하는 것을 목표로 합니다. 기여를 환영합니다.
