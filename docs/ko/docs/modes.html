비행 모드

모드는 송신기의 AUX 스위치를 통해 전환됩니다. 각 모드는 OrniFlight 구성기의 모드 탭에서 특정 AUX 채널 범위에 할당될 수 있습니다.

표준 모드

모드 기능
ARM 비행 제어 활성화(모터/서보 활성화)
ANGLE 스틱이 중앙에 위치하면 자동 레벨 — 공예가 레벨로 돌아갑니다
HORIZON 중앙 근처의 하이브리드 — 각도 모드, 풀 스틱의 아크로
ACRO 기본 — 자동 레벨 없음, 순수 속도 제어
AIRMODE 전체 권한을 위해 0 스로틀에서 PID 루프를 활성 상태로 유지

OrniFlight-특정 모드

ID 모드 기능
50 INDEPENDENT 독립적인 날개 제어 — 각 날개는 자체 서보 채널에 응답합니다
51 GLIDE 활공 모드 — 날개가 급상승하기 위해 수평 위치로 고정됨
52 PROFILE 비행 프로필 선택 — 3개의 PID/ONDAS 프로필 간 전환

유틸리티 모드

모드 기능
BEEPER 분실된 항공기를 찾기 위한 버저 활성화
BLACKBOX 블랙박스 로깅 시작/중지
FAILSAFE 안전 장치 2단계(패닉 스위치)를 수동으로 트리거
OSD OSD 표시 전환
TELEMETRY 원격 측정 출력 활성화/비활성화

오니톱터 노트

  • INDEPENDENT 모드는 OrniFlight —에 고유하며 비대칭 추력 및 차동 날개 제어를 위해 날개별 서보 매핑을 가능하게 합니다.
  • GLIDE 모드는 날개를 중립 위치에 유지하여 열 상승 및 에너지 효율적인 하강에 유용합니다.
  • PROFILE 전환을 통해 다양한 비행 조건(예: 순항 대 공격적 기동)에 대한 비행 중 ONDAS 매개변수 변경이 가능합니다.
