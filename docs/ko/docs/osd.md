# 화면 표시(OSD)

OrniFlight에는 MAX7456 또는 AT7456E 칩을 사용하는 내장형 OSD(온스크린 디스플레이)가 포함되어 있습니다. OSD는 비행 데이터를 FPV 비디오 피드에 오버레이합니다.

## 지원되는 요소

OrniFlight 구성기의 **OSD** 탭에서 요소를 구성합니다. 요소를 드래그 앤 드롭하여 화면에 배치하세요.

### 비행 데이터

| 요소 | 디스플레이 |
|---------|----------|
| 배터리 전압 | 메인 배터리 전압(예: 14.8V) |
| 평균 셀 전압 | 셀당 전압(예: 3.7V) |
| 현재 추첨 | 순간 앰프 |
| mAh 그린 | 누적 소비 용량 |
| RSSI | 수신기의 신호 강도 |
| 비행 모드 | 현재 모드(INDEPENDENT, GLIDE 등) |
| 스로틀 위치 | 현재 스로틀 비율 |
| 타이머 | 비행시간/무장시간 |
| 공예명 | OrniFlight 공예 이름 |

### Ornithopter 전용

| 요소 | 디스플레이 |
|------------|----------|
| 펄럭이는 빈도 | 현재 날개 스트로크 속도(Hz) |
| ONDAS 프로필 | 활성 항공편 프로필 번호(1-3) |
| Cadence 단계 | 전류 변조 위상 오프셋 |
| 서보 각도 | 윙 서보 위치 |

## 글꼴 관리

OSD는 문자 기반 디스플레이 시스템을 사용합니다. OrniFlight 구성기의 **OSD** 탭에는 사용자 정의 글꼴 및 글리프를 업로드하기 위한 **글꼴 관리자**가 포함되어 있습니다.

## CLI 설정

```
set osd_units = METRIC
set osd_warn_bitmask = 270335  # Warning flag bitmask
set osd_tim1 = 2560            # Timer 1 source
set osd_tim2 = 2561            # Timer 2 source
```

## 하드웨어

현재 지원되는 OSD 칩: **AT7456E**(OMNIBUSF4 및 호환 보드에 있음). MAX7456는 호환되며 자동 감지됩니다.
