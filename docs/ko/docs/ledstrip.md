# LED 스트립

OrniFlight는 상태 표시 및 시각적 피드백을 위해 주소 지정이 가능한 WS2812/SK6812 LED 스트립을 지원합니다.

## 구성

LED 스트립은 OrniFlight 구성기의 **LED Strip** 탭에서 구성됩니다. 각 LED 위치, 색상 및 기능은 개별적으로 설정할 수 있습니다.

## 기능

| 기능 | 시각효과 |
|------------|--------------|
| 배터리 표시기 | 녹색 → 노란색 → 빨간색의 색상 그라데이션 |
| RSSI | 신호 강도 표시 |
| 팔 상태 | 팔/해제 시 색상 변경 |
| 비행 모드 | 모드별 색상 |
| 경고 | 배터리 부족을 위한 깜박임 패턴, 안전 장치 |
| 플래핑 표시기 | 현재 플래핑 주파수의 펄스 |
| 추력 방향 | 롤/피치/요 출력을 나타내는 색상 이동 |
| GPS | 위성 잠금 및 홈 방향 |

## 하드웨어

- WS2812 또는 SK6812 RGB LED
- 비행 컨트롤러의 **LED** 패드/핀에 연결하세요.
- BEC의 전원 LED(3.3V —에서 5V를 사용하지 않음)
- 긴 스트립(8개 이상의 LED)의 경우 FC를 통하지 않고 배터리 패드에 직접 5V 전원을 연결합니다.

## 오르니톱터 사용

**플래핑 표시기**는 날개 스트로크 주파수와 동기화되는 OrniFlight — LED 펄스에 고유하며, 펄럭이는 리듬을 시각적으로 표현하고 ONDAS 케이던스 매개변수를 조정하는 데 도움이 됩니다.
