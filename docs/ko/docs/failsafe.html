안전 장치

안전 장치

OrniFlight에는 수신기 신호 손실 시 ornithopter를 보호하는 2단계 안전 시스템이 있습니다.

2단계 시스템

1단계 — 신호 손실 감지됨

다음과 같은 경우에 트리거됩니다. - 모든 비행 채널의 펄스 길이가 유효하지 않습니다. - 수신기가 안전 모드를 보고합니다. - 구성된 기간 동안 수신기로부터 신호가 없습니다.

조치: 모든 채널이 대체 값으로 전환됩니다(rxfail를 통해 구성됨). 신호가 반환되면 짧은 복구 기간이 —로 시작되고 정상적인 비행이 재개됩니다.

2단계 — 가드 시간 만료

1단계가 failsafe_delay(기본값: 400ms)보다 오래 지속되고 기체가 무장된 경우 입력됩니다.

절차(failsafe_procedure를 통해 구성 가능):

절차 행동
DROP 즉시 무장 해제 — 날개가 멈추고 항공기가 하강합니다
LAND 활공 모드 — 날개가 수평으로 고정되고 하강 제어됨

LAND는 오니톱터 —에 권장되는 절차입니다. 활공 하강을 위해 날개를 중립 위치에 유지하여 신호 복구 시간을 제공합니다.

CLI 설정

set failsafe_delay = 4 # Guard time in 0.1s (4 = 400ms) set failsafe_procedure = LAND # DROP or LAND set failsafe_throttle = 1000 # Fallback throttle (low) set failsafe_switch_mode = STAGE1 # Transmitter switch behavior

수신기 안전 장치

또한 신호 손실 시 펄스 없음을 출력하도록 수신기의 안전 장치를 구성하세요. 이를 통해 비행 컨트롤러는 손실을 감지하고 1단계를 활성화할 수 있습니다.

테스트

벤치에서 날개 연결 장치가 분리된 안전 장치를 테스트합니다. 1. 스위치에 FAILSAFE 모드 할당 2. 우주선을 무장시키세요 3. → 스위치를 토글하고 안전 장치 절차를 준수하십시오. 4. 서보 동작이 예상과 일치하는지 확인
