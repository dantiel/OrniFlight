# 컨트롤

OrniFlight는 ornithopter 특정 확장과 함께 표준 RC 스틱 매핑을 사용합니다.

## 스틱 매핑

| 스틱 | 축 | 1차 효과 |
|-------|------|---------------|
| 스로틀(왼쪽, 수직) | 스로틀 | 펄럭이는 진폭 / 추력 |
| 요(왼쪽, 수평) | 요 | 터닝을 위한 차동 날개 추력 |
| 피치(오른쪽, 수직) | 피치 | 앞으로/뒤로 기울이기 |
| 롤(오른쪽, 가로) | 롤 | 좌/우 뱅킹 |

## 비행 모드

| 모드 | 스틱 동작 |
|------|---------------|
| **ACRO** | 스틱 제어 각도 속도 — 자동 레벨 없음 |
| **ANGLE** | 놓을 때 스틱 제어 각도 — 자동 레벨 |
| **HORIZON** | 중앙 근처 ANGLE, 완전 편향 시 ACRO |

ACRO는 숙련된 조종사에게 권장됩니다. ANGLE는 첫 비행과 열폭등에 좋습니다.

## Ornithopter 전용 컨트롤

### INDEPENDENT 모드

INDEPENDENT 모드가 활성화되면 각 날개 서보가 독립적으로 반응합니다.
- **왼쪽 스틱** → 왼쪽 날개 서보
- **오른쪽 스틱** → 오른쪽 날개 서보
- 공격적인 기동을 위한 비대칭 플랩핑 가능

### GLIDE 모드

GLIDE 모드는 양쪽 날개를 수평 위치로 고정합니다. 오니톱터가 글라이더로 변합니다.
- **스로틀**은 날개 위치에 영향을 주지 않습니다.
- **피치/롤/요**는 여전히 테일 제어 표면에 영향을 미칩니다(장착된 경우).

### 프로필 전환

AUX 채널을 통한 기내 프로필 전환을 통해 비행 중에 PID/ONDAS 매개변수를 변경할 수 있습니다.
- **프로필 1**: 표준 크루즈 설정
- **프로필 2**: 높은 민첩성 설정
- **프로필 3**: 효율성/글라이드 설정

## 요금

**PID Tuning** 탭에서 속도를 구성합니다. ornithopter의 경우 보수적인 속도 — 플래핑 역학으로 시작하여 제어 입력을 증폭시킵니다.
- RC 비율: 0.80–1.00
- 슈퍼레이트: 0.60–0.70
- 엑스포: 0.20–0.40
