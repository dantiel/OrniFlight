# 시작하기

OrniFlight에 오신 것을 환영합니다! 이 가이드는 ornithopter 비행 컨트롤러의 초기 설정 과정을 안내합니다.

## 필요한 것

- **OrniFlight 구성자** — [orniflight.org](https://orniflight.org)에서 다운로드
- 비행 컨트롤러를 컴퓨터에 연결하는 **USB 케이블** —
- **Ornithopter** 포함:
  - 지원되는 비행 컨트롤러(OMNIBUSF4, TINYFISH)
  - 날개 작동을 위한 서보
  - 송신기에 연결된 수신기
  - 배터리 (2S–4S LiPo)

## 빠른 시작

### 1. 플래시 펌웨어

1. **OrniFlight 구성 프로그램**을 엽니다.
2. **펌웨어 플래셔** 탭으로 이동합니다.
3. 보드 대상(OMNIBUSF4 또는 TINYFISH)을 선택합니다.
4. 최신 안정 버전을 선택하세요
5. **펌웨어 로드**를 클릭한 다음 **펌웨어 플래시**를 클릭합니다.

### 2. 초기 구성

깜박인 후 구성기는 사용자 정의 기본값을 적용하라는 메시지를 표시합니다. **항상 수락하세요.**

### 3. 수신기 설정

1. **포트** 탭으로 이동합니다. → 올바른 UART를 `Serial RX`로 설정합니다.
2. **구성** 탭 →로 이동하여 수신기 프로토콜(CRSF, SBUS 등)을 선택합니다.
3. **수신기** 탭 →로 이동하여 스틱 움직임이 예상 채널과 일치하는지 확인합니다.
4. 채널 끝점 설정: 1500 중심의 1000–2000

### 4. 서보 설정

1. **서보** 탭으로 이동합니다.
2. 서보 매핑이 ornithopter의 날개 구성과 일치하는지 확인하십시오.
3. 필요한 경우 서보 방향 — 역방향 테스트
4. 중앙 위치 설정(날개 수평 = 1500)

### 5. 모드 설정

1. **모드** 탭으로 이동합니다.
2. ARM를 AUX 스위치에 할당
3. 비행 모드(ANGLE / ACRO / HORIZON)를 원하는 대로 지정하세요.
4. 예비 스위치에 INDEPENDENT 및 GLIDE 할당
5. 분실 모델 찾기를 위해 BEEPER 구성

### 6. 첫 비행

1. **벤치 테스트를 위해 날개 연결 장치 분리**
2. 서보 작동 방향을 준비하고 확인합니다.
3. 스로틀 반응을 확인하세요
4. 첫 번째 실제 비행의 경우: ANGLE 모드를 사용하고 요금이 저렴합니다.
5. 눈높이에 마우스를 놓고 필요에 따라 다듬습니다.
