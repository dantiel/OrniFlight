# 설치

비행 컨트롤러에 OrniFlight 펌웨어를 설치하는 방법.

## 전제 조건

- **OrniFlight 구성자**(최신 버전)
- USB 데이터 케이블(충전 전용 아님)
- 지원되는 비행 컨트롤러 보드

## 지원되는 보드

| 보드 | 대상 | 플래시 | 메모 |
|-------|---------|-------|-------|
| OMNIBUSF4 | `OMNIBUSF4` | 16MB | STM32F405, MPU6000, OSD |
| TINYFISH | `TINYFISH` | 256KB | STM32F411, MPU6000 |

## 깜박이는 단계

### 1. DFU/부트로더 모드로 들어갑니다.

**OMNIBUSF4**: USB를 연결하는 동안 BOOT 버튼을 길게 누르세요. 빨간색 LED는 계속 켜져 있습니다. — DFU 모드에 있습니다.

**TINYFISH**: USB를 연결하는 동안 BOOT 버튼을 누르고 있습니다.

### 2. 구성기를 통한 플래시

1. OrniFlight 구성 프로그램 열기
2. **펌웨어 플래셔** 탭으로 이동합니다.
3. 드롭다운에서 대상을 선택하세요.
4. 펌웨어 버전을 선택하세요(안정적인 최신 버전 권장).
5. **펌웨어 로드(온라인)**을 클릭하거나 로컬 16진수 파일을 선택합니다.
6. **플래시 펌웨어**를 클릭합니다.
7. "프로그래밍: 성공"을 기다립니다.

### 3. 첫 번째 연결

깜박인 후:
1. USB 연결을 끊었다가 다시 연결합니다(BOOT 버튼 없음).
2. 구성자는 자동 연결되어야 합니다.
3. "사용자 정의 기본값 적용" 프롬프트를 수락합니다.
4. 설정 탭에서 보드 정보를 확인합니다.

## 문제 해결

### DFU 포트 없음

**macOS/Linux**: DFU가 자동으로 나타납니다. 그렇지 않은 경우:
```bash
# Check for DFU device
system_profiler SPUSBDataType | grep -A 10 STM
```

**Windows**: STM32 DFU 드라이버를 교체하려면 [Zadig](https://zadig.akeo.ie/)를 설치하십시오.
1. Zadig 실행
2. 옵션 → 모든 장치 나열
3. "STM32 BOOTLOADER"를 선택하세요
4. 드라이버를 "WinUSB"로 교체합니다.

### 플래시 실패

- 다른 USB 케이블을 사용해 보세요(충전 전용이 아닌 데이터 가능).
- 다른 USB 포트를 사용해 보십시오(허브가 아닌 직접).
- 플래시 프로세스 내내 BOOT 버튼을 누르고 있습니다.
- **OMNIBUSF4**: 전체 칩 삭제가 필요할 수 있습니다. — "전체 칩 삭제" 옵션을 확인하세요.

### 구성자가 연결되지 않습니다

- USB 케이블이 데이터를 지원하는지 확인하세요.
- 보드가 DFU 모드가 아닌지 확인하십시오(LED 깜박임 = 일반 모드).
- 구성자 다시 시작
- 다른 USB 포트를 사용해 보십시오.

## CLI 플래시(고급)

고급 사용자의 경우 STM32CubeProgrammer 또는 st-flash를 통해 플래시합니다.

```bash
st-flash write orniflight_0.4.6_OMNIBUSF4.hex 0x08000000
```

깜박인 후 다음을 통해 확인하세요.

```bash
st-flash verify orniflight_0.4.6_OMNIBUSF4.hex 0x08000000
```
