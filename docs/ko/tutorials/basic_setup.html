기본 설정

첫 번째 비행을 위해 오니홉터를 구성하세요.

비행 전 체크리스트

다른 것보다 먼저:

  • [ ] 비행 컨트롤러가 OrniFlight로 깜박임
  • [ ] 송신기에 바인딩된 수신기
  • [ ] PWM 출력을 수정하기 위해 연결된 서보
  • [ ] 배터리 연결됨(날개가 고정됨!)

수신기 설정

CRSF (권장)

  1. 포트 탭: UART(예: UART1)를 “직렬 RX”로 설정합니다.
  2. 구성 탭: 수신기 모드 = “직렬 기반 수신기”, 공급자 = “CRSF”
  3. 전원을 껐다 켜고 채널 입력이 수신기 탭에서 이동하는지 확인합니다.

SBUS / 기타

동일한 프로세스 —는 구성 탭에서 적절한 프로토콜을 선택합니다.

서보 매핑

서보 탭에서:

서보 기능 기본율
서보 0 좌익 250Hz
서보 1 우익 250Hz
서보 2 문장/방향타 50Hz

서보의 범위에 맞게 최소/최대/중간을 조정하세요. “재정의”로 테스트하여 방향을 확인하세요.

비행 모드 선택

모드 탭에서:

  1. ARM: 스위치에 할당(안전!)
  2. ORNITHOPTER INDEPENDENT 또는 ORNITHOPTER GLIDE: 기본 비행 모드를 선택하세요.
  3. ORNITHOPTER PROFILE: 기내 프로필 전환을 위한 — 할당 옵션

ONDAS 첫 번째 튜닝

고급 → ONDAS 하위 탭으로 이동하세요.

  1. Cadence 게인: 50(중간)에서 시작합니다. 이것이 가장 중요한 매개 변수입니다.
  2. Ferocity D 게인: 30에서 시작합니다. 이것이 기본 안정화입니다.
  3. Ferocity P 게인: 롤/피치의 경우 20, 요의 경우 0에서 시작합니다.
  4. Balance 게인: 0(중앙).

배터리를 연결하고 오니톱터를 단단히 고정하고 ARM를 수행합니다. 서보 움직임 —를 관찰하면 부드럽고 사인파형으로 펄럭이는 것이어야 합니다.

첫 비행

  1. 바람에 가볍게 던지면서 시작하세요.
  2. 자연스러운 솟아오르는 느낌을 원하시면 GLIDE 모드를 사용하세요
  3. 직접 주파수 제어를 원할 경우 INDEPENDENT 모드를 사용하십시오.
  4. 착륙하고, ONDAS를 조정하고, 반복하세요.
