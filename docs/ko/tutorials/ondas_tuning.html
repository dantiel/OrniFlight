ONDAS 튜닝 가이드

ONDAS 이론 —의 실제적인 동반자로서 느낌에 따라 각 매개변수를 조정하는 방법.

튜닝 순서

ONDAS 매개변수는 상호 의존적입니다. 다음 순서로 조정하세요.

1. Cadence → timing 2. Ferocity D → primary stabilization 3. Ferocity P → response crispness 4. Balance → upstroke/downstroke bias 5. Warp → modulation width 6. Anchor → dry/wet mix 7. Resonance → cycle-to-cycle memory 8. Phase 2 → advanced (prescience, espelho, saudade, SSFF)

단계별

1. Cadence — 단계 찾기 창

목표: 날개가 가장 많이 물리는 곳에 모듈레이션을 배치합니다.

방법: - 50부터 시작 - 70 —로 올리면 롤 반응이 약해지나요? - 30 —로 줄이면 롤 반응이 강해지나요? - “가장 강한” 지점은 날개의 파워 스트로크가 최고조에 달하는 지점입니다.

너무 높음의 징후: 흐릿한 반응, 공예가 “지연된” 느낌 너무 낮은 징후: 갑작스러운 반응, 롤 오버슈트

2. Ferocity D — 기술을 안정시키세요

목표: 진동 없이 1차 안정화.

방법: - 20부터 시작 - 호버링 또는 꾸준한 전진 비행 - 공예가 “뻣뻣해진다”는 느낌이 들 때까지 늘리세요. - 처음 진동을 느낀 지점에서 5개 지점을 뒤로 물러서세요.

너무 높은 징후: 미세한 진동, 서보의 모터 같은 윙윙거림 너무 낮은 징후: 기체가 표류하고 느슨한 느낌

3. Ferocity P — 바삭함

목표: 반응이 빠르지만 경련을 일으키지는 않습니다.

방법: - 15시부터 시작 - 범프 더 롤 스틱 — 공예품이 즉시 물릴까요? - 스틱 반응이 선명해질 때까지 증가시킵니다. - 오버슛이 보이면 물러서세요.

너무 높음의 징후: 스틱 입력 후 벨 소리, 바운스백 너무 낮은 징후: 흐릿하고 반응이 지연됨

4. Balance — 비대칭 튜닝

목표: 양방향에서 동일한 권한을 부여합니다.

방법: - 직선으로 수평으로 비행 - 왼쪽으로 굴림, 응답 속도 확인 - 오른쪽으로 굴러 반응 속도 확인 - 균형을 맞춰 균형을 맞추세요.

5–7. Warp, Anchor, Resonance

매개변수를 미세 조정합니다. 1~4가 확실한 이후에만 조정하세요.

파람 시작 조정 시기
Warp 50 변조가 너무 퍼져 있거나 너무 뾰족한 느낌
Anchor 70 더 많거나 더 적은 원시 PID 혼합을 원함
Resonance 30 호버링이 불안정하거나 앞으로 비행할 때 벨소리가 울리는 느낌

8. Phase 2 — 고급

파람 효과
Prescience 타이밍 어드밴스 — 더 높음 = 변조가 위상을 더 앞당김
Espelho 차동 커플링 — 롤이 더 단단해지면 효율성이 저하될 수 있음
Saudade 스트로크 메모리 — 더 부드럽지만 응답성이 떨어짐
SSFF 직접 gyro→wave 주입 — 10시 시작

목표는 공중에 떠 있고 싶은 것처럼 날아가는 비행체입니다. 맞서 싸우고 있다면 물러서서 Cadence에서 다시 조정하세요.
