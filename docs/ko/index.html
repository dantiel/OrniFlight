선언문

비행 제어기의 새로운 종

OrniFlight는 펄럭이는 날개가 단일 스트로크 내에서 추력, 피치, 롤 및 요를 제어하기 때문에 존재합니다. 이는 프로펠러가 일치시킬 수 없는 표현성의 채널입니다.

Nature solved flapping-wing flight 150 million years before the first quadcopter took off. Every sparrow, every albatross, every hummingbird carries flight logic in its nervous system that no PID controller has ever replicated. OrniFlight opens a new domain — where thrust is phase, where stability is rhythm, where the aircraft breathes with every wingbeat. ONDAS, our Oscillating Normalized Dynamic Adaptive Stabilization, is the first control theory built from first principles for flapping aerodynamics. It modulates correction force within the wingbeat — not against it, not despite it, but with it. This firmware is free software because flight belongs to no corporation. It runs on commodity STM32F3 hardware because the tools for transcendent flight should cost less than a dinner. OrniFlight inherits a battle-tested architecture and pushes into uncharted air — a new species of flight controller, built for wings from the silicon up. The birds have been waiting for us to catch up.

CRSF → rx → OrniFlight → ONDAS → waveform → PWM servos → wings

ONDAS

진동 정규화 동적 적응 안정화

진동 정규화된 동적 적응 안정화 (Oscillating Normalized Dynamic Adaptive Stabilization) — 날개 공기역학을 위해 특별히 제작된 최초의 제어 이론.

쿼드 PID는 연속 추력을 가정합니다. Ornithopter 추력은 위상적입니다. 동일한 임펄스는 스트로크에 적용된 시점에 따라 다른 순간을 생성합니다. 온다스는 케이던스, 격렬함, 비대칭성, 워프, 앵커, 공명, 프리시언스, 에스펠류, 사우데이드 및 SSFF (위상 인식 변조기의 오케스트라) 를 사용하여 모든 교정 그램을 공기 역학이 사용할 수 있는 곳에 정확히 배치합니다.

cadence · ferocity · asymmetry · warp · anchor · resonance · prescience · espelho · saudade · SSFF

기능

날개가 받을 자격이 있는 모든 것

비행 프로필
4개의 독립 프로파일 (0–3), 박스 모드를 통해 기내 전환 가능. 각각은 완전한 온다스 튜닝, 파형 및 공탄성 계수를 보유합니다.
통합 주파수 채널
최소/최대 Hz 매핑이 있는 단일 RC 채널. 독립 및 활공 비행 모드에서 동일하게 작동합니다 — 하나의 냄비, 두 체제 모두.
GralhaAzul 날개 역학
서보 속도 제한, 진폭 매핑, 플랩 크기 및 날개 원점 형상을 가진 사다리꼴 파형 생성 — 날개-ODE 코어.
10채널 ONDAS 변조
케이던스 타이밍, 3축의 강렬한 P/D, 밸런스, 워프, 앵커, 공명 — 프로필당, MSP를 통해 실시간 조정 가능.
MSP 구성기 (apiVersion 1.46)
전체 온다스 튜닝 GUI — 모든 19 프로파일 필드, 주파수 채널, GralhaAzul, 2단계 이득. 슬롯당 편집을 위한 프로필 스위처.
GLIDE 및 INDEPENDENT 모드
두 가지 비행 체제: 글라이드 (스로틀 중심, 자연 치솟음) 및 독립 (RC 채널을 통한 직접 플랩 주파수). BOX 선택 가능.

하드웨어

STM32F3/F4/F7 비행 제어기

서보 기능 타이머 핀이 있는 모든 Betaflight 4.0 호환 STM32F3/F4/F7 비행 컨트롤러에서 실행됩니다.

타겟 TINYFISH (F3, 통합 FrSky RX), OMNIBUSF4, MATEKF405, KAKUTEF7…
서보 출력 최대 4개의 프로그래밍 가능한 서보 채널, 50-400Hz PWM
수신기 CRSF (Crossfire/ExpressLRS), SBUS, Spektrum, SUMD — TINYFISH에 통합된 FrSky
플래시 256 KB (TINYFISH F3) / 1 MB (OMNIBUSF4)
RAM 40 KB (TINYFISH F3) / 192 KB (OMNIBUSF4)

시작하기 →

빌드 및 플래시

make TARGET=TINYFISH\ndfu-util -a 0 -D obj/orniflight_VERSION_TINYFISH.hex

# or for OMNIBUSF4:
make TARGET=OMNIBUSF4\ndfu-util -a 0 -D obj/orniflight_VERSION_OMNIBUSF4.hex
