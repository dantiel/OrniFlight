# Начало работы

Добро пожаловать в OrniFlight! Это руководство проведет вас через первоначальную настройку контроллера полета орнитоптера.

## Что вам нужно

- **OrniFlight Конфигуратор** — скачать с [orniflight.org](https://orniflight.org)
- **кабель USB** — для подключения полетного контроллера к компьютеру.
- **Орнитоптер** с:
  - Поддерживаемый полетный контроллер (OMNIBUSF4, TINYFISH)
  - Сервоприводы для приведения в действие крыла
  - Приемник привязан к вашему передатчику
  - Аккумулятор (2S–4S LiPo)

## Быстрый старт

### 1. Прошить прошивку

1. Откройте **Конфигуратор OrniFlight**.
2. Перейдите на вкладку **Прошивка**.
3. Выберите цель доски (OMNIBUSF4 или TINYFISH).
4. Выберите последнюю стабильную версию.
5. Нажмите **Загрузить прошивку**, затем **Загрузить прошивку**.

### 2. Первоначальная настройка

После прошивки Конфигуратор предложит применить пользовательские настройки по умолчанию. **Всегда соглашайтесь.**

### 3. Настройка приемника

1. Перейдите на вкладку **Порты**. → установите правильный UART на `Serial RX`.
2. Перейдите на вкладку **Конфигурация** → и выберите протокол приемника (CRSF, SBUS и т. д.).
3. Перейдите на вкладку **Приемник** → и убедитесь, что движения джойстика соответствуют ожидаемым каналам.
4. Установите конечные точки канала: 1000–2000 с центром 1500.

### 4. Настройка сервопривода

1. Перейдите на вкладку **Сервоприводы**.
2. Убедитесь, что отображение сервоприводов соответствует конфигурации крыла вашего орнитоптера.
3. При необходимости проверьте направление сервопривода — на обратное.
4. Установите центральное положение (крылья по горизонтали = 1500).

### 5. Настройка режимов

1. Перейдите на вкладку **Режимы**.
2. Назначьте ARM переключателю AUX.
3. Назначьте режимы полета (ANGLE/ACRO/HORIZON) по желанию.
4. Назначьте INDEPENDENT и GLIDE запасным переключателям.
5. Настройте BEEPER для поиска потерянной модели.

### 6. Первый полет

1. **Отсоедините тягу крыла для стендовых испытаний**
2. Активируйте и проверьте направление движения сервопривода.
3. Проверьте реакцию дроссельной заслонки.
4. Для первого реального полета: используйте режим ANGLE, низкие тарифы.
5. Наведите курсор на уровень глаз, обрежьте при необходимости
