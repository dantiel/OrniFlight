Первая вспышка

Пошаговая установка OrniFlight на полетный контроллер —.

Что вам нужно

  • полетный контроллер на базе STM32F4 (OMNIBUSF4, TINYFISH, MATEKF405 и т.д.) — кабель USB
  • dfu-util или STM32CubeProgrammer
  • файл OrniFlight .hex со страницы релизов

Шаг 1: Войдите в режим DFU

  1. Удерживайте кнопку BOOT на полетном контроллере.
  2. Подключите USB, удерживая кнопку.
  3. Отпустите через 2 секунды.

Проверьте на macOS/Linux:

dfu-util -l

Должно показывать Found DFU: [0483:df11]

Шаг 2: Прошивка

dfu-util -a 0 -D obj/orniflight_0.4.6_OMNIBUSF4.hex

Шаг 3: Первая загрузка

  1. Отключите USB.
  2. Подключите USB обратно (не удерживайте BOOT).
  3. Подключаемся через конфигуратор OrniFlight.

Шаг 4: Базовая конфигурация

В Конфигураторе:

  1. Вкладка «Порты»: настройте UART для вашего приемника (Serial RX).
  2. Вкладка «Конфигурация»: выберите протокол приемника (рекомендуется CRSF).
  3. Вкладка «Режимы»: настройте переключатели ARM, GLIDE/INDEPENDENT и PROFILE.
  4. Вкладка «Дополнительно» → ONDAS: просмотрите настройки по умолчанию, сначала настройте Cadence.

Устранение неполадок

Проблема Исправить
устройство DFU не найдено Попробуйте другой кабель USB, проверьте кнопку BOOT
Вспышка не работает Проверьте установку dfu-util, разрешения USB
Нет загрузки после прошивки Перепрошить, убедиться, что шестнадцатеричный код соответствует вашей цели
Конфигуратор не подключается Проверьте порт COM и скорость передачи данных
