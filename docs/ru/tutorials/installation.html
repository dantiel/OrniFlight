Установка

Как установить прошивку OrniFlight на полетный контроллер.

Предварительные условия

  • OrniFlight Конфигуратор (последняя версия)
  • кабель для передачи данных USB (не только для зарядки)
  • Поддерживаемая плата контроллера полета

Поддерживаемые платы

Совет Цель Флэш Заметки
OMNIBUSF4 OMNIBUSF4 16 МБ STM32F405, MPU6000, OSD
TINYFISH TINYFISH 256 КБ STM32F411, MPU6000

Шаги мигания

1. Войдите в DFU/режим загрузчика.

OMNIBUSF4: удерживайте кнопку BOOT во время подключения USB. Красный LED горит постоянно. — — вы находитесь в режиме DFU.

TINYFISH: удерживайте кнопку BOOT во время подключения USB.

2. Прошить через Конфигуратор

  1. Откройте конфигуратор OrniFlight.
  2. Перейдите на вкладку Прошивка.
  3. Выберите цель из раскрывающегося списка.
  4. Выберите версию прошивки (рекомендуется последняя стабильная версия)
  5. Нажмите Загрузить прошивку (онлайн) или выберите локальный шестнадцатеричный файл.
  6. Нажмите Обновить прошивку.
  7. Дождитесь сообщения «Программирование: УСПЕШНО».

3. Первое подключение

После прошивки: 1. Отключите и снова подключите USB (без кнопки BOOT) 2. Конфигуратор должен автоматически подключиться 3. Примите приглашение «Применить пользовательские настройки по умолчанию». 4. Проверьте информацию о плате на вкладке «Настройка».

Устранение неполадок

Нет порта DFU

macOS/Linux: DFU должен появиться автоматически. Если нет: bash # Check for DFU device system_profiler SPUSBDataType | grep -A 10 STM

Windows: установите Zadig, чтобы заменить драйвер STM32 DFU: 1. Беги Задиг 2. Параметры → Список всех устройств 3. Выберите «STM32 BOOTLOADER». 4. Замените драйвер на «WinUSB».

Сбой флэш-памяти

  • Попробуйте другой кабель USB (с возможностью передачи данных, а не только для зарядки).
  • Попробуйте другой порт USB (прямой, а не концентратор)
  • Удерживайте кнопку BOOT на протяжении всего процесса прошивки.
  • OMNIBUSF4: может потребоваться полное стирание чипа. — отметьте опцию «Полное стирание чипа».

Конфигуратор не подключается

  • Убедитесь, что кабель USB поддерживает передачу данных.
  • Проверьте, что плата не находится в режиме DFU (LED мигает = нормальный режим)
  • Перезапустить конфигуратор
  • Попробуйте другой порт USB.

CLI Flash (продвинутый)

Для продвинутых пользователей прошивайте через STM32CubeProgrammer или st-flash:

bash st-flash write orniflight_0.4.6_OMNIBUSF4.hex 0x08000000

После прошивки проверьте:

bash st-flash verify orniflight_0.4.6_OMNIBUSF4.hex 0x08000000
