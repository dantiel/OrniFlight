# Базовая настройка

> *Настройте свой орнитоптер для первого полета.*

## Предполетный контрольный список

Прежде всего:

- [ ] Контроллер полета прошит с помощью OrniFlight
- [ ] Приемник привязан к передатчику
- [ ] Сервоприводы подключены к правильным выходам PWM.
- [ ] Аккумулятор подключен (крылья закреплены!)

## Настройка приемника

### CRSF (рекомендуется)

1. **Вкладка «Порты»**: установите для UART (например, UART1) значение «Serial RX».
2. **Вкладка «Конфигурация»**: Режим приемника = «Последовательный приемник», Поставщик = «CRSF»
3. Выключите и включите питание, убедитесь, что входы каналов перемещаются на вкладке «Приемник».

### SBUS / Другое

Тот же процесс — выбирает соответствующий протокол на вкладке «Конфигурация».

## Отображение сервоприводов

На вкладке **Сервоприводы**:

| Сервопривод | Функция | Ставка по умолчанию |
|-------|----------|-------------|
| Сервопривод 0 | Левое крыло | 250 Гц |
| Сервопривод 1 | Правый фланг | 250 Гц |
| Сервопривод 2 | Гребень/руль направления | 50 Гц |

Отрегулируйте мин/макс/средний диапазон в соответствии с диапазоном вашего сервопривода. Протестируйте с помощью «Override», чтобы проверить направление.

## Выбор режима полета

На вкладке **Режимы**:

1. **ARM**: назначить переключатель (безопасность!)
2. **ORNITHOPTER INDEPENDENT** или **ORNITHOPTER GLIDE**: выберите основной режим полета.
3. **ORNITHOPTER PROFILE**: Дополнительное назначение — для переключения профиля в полете.

## ONDAS Первая настройка

Перейдите на вкладку **Дополнительные → ONDAS**:

1. **Усиление Cadence**: начните с 50 (средний). Это самый важный параметр.
2. **Ferocity D Gain**: начните с 30. Это ваша основная стабилизация.
3. **Ferocity P Усиление**: начните с 20 для крена/тангажа, 0 для рыскания.
4. **Balance Усиление**: 0 (по центру).

Подсоедините аккумулятор, **надежно закрепите орнитоптер** и нажмите ARM. Наблюдайте за движением сервопривода —, оно должно быть плавным, синусоидальным.

## Первый полет

1. Начните с легкого броска против ветра.
2. Используйте режим GLIDE для естественного ощущения парения.
3. Используйте режим INDEPENDENT, если вам нужно прямое управление частотой.
4. Приземлитесь, отрегулируйте ONDAS, повторите.
