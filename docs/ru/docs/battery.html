Мониторинг батареи

OrniFlight контролирует напряжение основной батареи через ADC (аналогово-цифровой преобразователь). Это позволяет предупреждать о низком заряде батареи с помощью зуммера, полос состояния LED и LED.

Особенности

  • Автоматическое определение количества ячеек при подключении (на основе минимального/максимального напряжения ячейки)
  • Предупреждение о низком заряде батареи с настраиваемыми пороговыми значениями
  • Измерение тока потребления мАч (если поддерживается FC)
  • Напряжение отображается в формате OSD и передается посредством телеметрии.

Поддерживаемые цели

Все поддерживаемые полетные контроллеры (OMNIBUSF4, TINYFISH) включают мониторинг VBAT через делитель напряжения.

Соединения

ВСЕГДА ПРОВЕРЯЙТЕ ПОЛЯРНОСТЬ. Перед подключением измерьте ожидаемое напряжение. Неправильное напряжение или неправильная полярность могут привести к поломке вашего полетного контроллера.

OMNIBUSF4

Подключите основной аккумулятор к панели VBAT. Встроенный делитель напряжения напрямую обрабатывает напряжение до 6S.

TINYFISH

VBAT подключается через вход питания платы. — отдельное подключение не требуется.

CLI Настройки

set vbat_min_cell_voltage = 330 # Minimum per-cell voltage (3.3V) set vbat_max_cell_voltage = 430 # Maximum per-cell voltage (4.3V) set vbat_warning_cell_voltage = 350 # Warning threshold (3.5V) set battery_meter_type = ADC set current_meter_type = ADC # If current sensor available

Безопасность

Батареи LiPo никогда не следует разряжать ниже 3,5 В на элемент под нагрузкой. Настраиваемые пороговые значения OrniFlight помогают обеспечить безопасную работу и долговечность батареи.
