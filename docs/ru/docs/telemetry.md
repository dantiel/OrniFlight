# Телеметрия

Телеметрия отправляет данные полета с OrniFlight на ваш радиопередатчик —, напряжение батареи, ток, координаты RSSI, GPS, высоту и многое другое.

## Поддерживаемые протоколы

| Протокол | Радиосистема | Количество проводов |
|----------|-------------|------------|
| **CRSF** | Перекрестный огонь / Трейсер / ELRS | Интегрировано с RX (двунаправленное) |
| **SmartPort** | FrSky | 1 провод (контакт TX) |
| **HoTT** | Граупнер | 1 провод (TX+TZ) |
| **IBUS** | FlySky | 1 провод (датчик TX) |
| **LTM** | Световая телеметрия (MWP) | 1 провод (TX) |

## Конфигурация

1. В Конфигураторе → **Порты**: установите для вывода UART TX соответствующий протокол телеметрии.
2. Включите функцию телеметрии: `feature TELEMETRY`.
3. При необходимости настройте инверсию телеметрии.

Для **CRSF** телеметрия обрабатывается автоматически. — отдельный порт не требуется.

## SmartPort (FrSky)

SmartPort требует инверсии сигнала на процессорах F4. Либо:
- Используйте полетный контроллер со встроенным инвертором.
- Используйте SoftSerial с `set tlm_inversion = ON`.

```
feature TELEMETRY
set tlm_inverted = ON
set tlm_halfduplex = ON
```

## Данные телеметрии

OrniFlight передает:
- напряжение VBAT (основной аккумулятор)
- Ток потребления/мАч потребляемый
- RSSI (сила сигнала)
- Режим полета/статус охраны
- координаты GPS (если есть)
- Высота/варио (если барометр)
- профиль полета ONDAS активен
