Ведение журнала черного ящика

Blackbox записывает данные полета для послеполетного анализа, настройки и отладки. OrniFlight поддерживает запись на встроенный флэш-чип или внешнее устройство OpenLog.

Что регистрируется

  • Гироскоп — необработанная и отфильтрованная угловая скорость по 3 осям
  • Акселерометр — 3-осевое ускорение
  • PID Выход — Вклад P, I, D, F на ось
  • ONDAS — Cadence, Ferocity P/D и другие параметры, специфичные для взмахов
  • Команды RC — позиции джойстика после ставок/экспонирования
  • Сервовыход — окончательный выход на каждый сервоканал
  • Батарея — напряжение и ток на итерацию
  • GPS — положение, скорость, высота (если доступно)

Настройка

Встроенная вспышка (OMNIBUSF4)

OMNIBUSF4 включает в себя встроенную флэш-память емкостью 16 МБ для ведения журналов Blackbox. Включить в Конфигураторе:

  1. Вкладка Черный ящик → Установите для Blackbox logging device значение Onboard flash.
  2. Установите скорость регистрации (рекомендуется: 1/N с N=2-4 для целей F4)
  3. Назначьте переключатель для запуска/остановки регистрации.

Внешний OpenLog

Подключите OpenLog к бесплатному контакту UART TX:

  1. Вкладка Порты → Установите для UART значение Blackbox logging на скорости 115200 бод.
  2. Подключите OpenLog: FC TX → OpenLog RX, плюс 5 В/GND

Инструменты анализа

  • Blackbox Explorer — веб-просмотрщик журналов
  • blackbox_decode — конвертировать в CSV для пользовательского анализа

ONDAS-специфично

Blackbox необходим для настройки параметров ONDAS. Зарегистрированные данные ONDAS включают в себя: - ondas_cadence_phase — синхронизация окна модуляции - ondas_ferocity_p/ondas_ferocity_d — асимметричные компоненты тяги - ondas_balance — баланс левого/правого крыла - Выход каждого сервопривода на каждой итерации

Это позволяет точно анализировать механику взмахов и корректировать асимметрию крыла.
