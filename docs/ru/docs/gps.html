GPS

GPS обеспечивает удержание позиции, возврат домой и навигацию на основе телеметрии для вашего орнитоптера. Функции GPS в OrniFlight функциональны, но считаются экспериментальными. — всегда летает в пределах прямой видимости.

Поддерживаемые протоколы

  • UBLOX (рекомендуется) — бинарный протокол Ublox, эффективный и надежный
  • NMEA — Стандартный текстовый протокол

Аппаратное обеспечение

  • BN-880, BN-220 или аналогичные модули Ublox M8N GPS+Компас
  • Подключите: TX/RX к бесплатному UART, плюс 5V/GND.
  • Устанавливайте GPS подальше от силовых проводов и сервокабелей, чтобы минимизировать помехи.
  • Компас/магнитометр должен находиться вдали от источников магнитного поля (провода питания, сервоприводы)

Конфигурация

feature GPS set gps_provider = UBLOX set gps_sbas_mode = AUTO set gps_auto_baud = ON set gps_ublox_use_galileo = ON

  1. Назначьте последовательный порт для GPS на вкладке Порты (по умолчанию 115200 бод для UBlox).
  2. Включите функцию GPS.
  3. Установите провайдера
  4. Сохраняем и перезагружаемся.

OSD Элементы

Данные GPS, отображаемые в OSD, включают: - Количество спутников и тип исправления - координаты GPS (широта/долгота) - Скорость относительно земли - Высота (GPS) - Расстояние от дома - Стрелка направления домой

Соображения об орнитоптерах

  • Антенна GPS должна иметь хороший обзор неба. Место установки — имеет решающее значение при наличии машущих крыльев.
  • На небольших орнитоптерах значительное снижение веса.
  • RTH с поддержкой GPS (возврат домой) требует тщательной настройки навигационных значений PID для динамики полета взмахов.
