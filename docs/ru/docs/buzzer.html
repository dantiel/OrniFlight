Зуммер

Зуммер

OrniFlight поддерживает активные зуммеры для звуковой индикации состояния и определения местоположения потерянной модели.

Функции

  • Постановка/снятие с охраны — отдельные звуки
  • Низкий заряд батареи — повторяющиеся предупреждающие звуковые сигналы
  • Отказоустойчивый шаблон — SOS
  • Потерянная модель — непрерывный звуковой сигнал через переключатель
  • GPS Fix — тональный сигнал подтверждения при блокировке спутника.
  • Калибровка — звуковые сигналы во время калибровки гироскопа/ускорения
  • RX Потеря сигнала — предупреждение при разрыве соединения с приемником

Аппаратное обеспечение

  • Подключите активный зуммер 5 В (НЕ пассивный пьезоэлектрический преобразователь) к контактам BUZZ- и BUZZ+.
  • Зуммер управляется транзистором на FC —, для стандартных зуммеров внешний драйвер не требуется.

CLI Настройки

beeper -GYRO_CALIBRATED # Disable gyro calibration beeps beeper -RX_LOST # Enable receiver lost warning beeper -ON_USB # Disable beeper when USB connected

Безопасность орнитоптера

Звуковой сигнал особенно полезен для крупных орнитоптеров, которые могут приземлиться в высокой траве или листве. Настройте режим BEEPER на переключателе мгновенного действия для быстрой активации при необходимости.
