# Режимы полета

Режимы переключаются с помощью переключателей AUX на передатчике. Каждый режим можно назначить определенному диапазону каналов AUX на вкладке **Режимы** конфигуратора OrniFlight.

## Стандартные режимы

| Режим | Функция |
|------|----------|
| **ARM** | Включить управление полетом (двигатели/сервоприводы активны) |
| **ANGLE** | Автоматический уровень — корабль возвращается на уровень, когда стик находится в центре |
| **HORIZON** | Гибридный режим угла — ближе к центру, акробатика при полном стике |
| **ACRO** | По умолчанию — без автоматического уровня, чистый контроль скорости |
| **AIRMODE** | Сохраняет цикл PID активным при нулевом газе для обеспечения полных полномочий |

## OrniFlight Специальные режимы

| ID | Режим | Функция |
|----|------|----------|
| 50 | **INDEPENDENT** | Независимое управление крылом — каждое крыло реагирует на собственный сервоканал |
| 51 | **GLIDE** | Режим планирования — крылья фиксируются в горизонтальном положении для парения |
| 52 | **PROFILE** | Выбор профиля полета — переключение между 3 профилями PID/ONDAS |

## Служебные режимы

| Режим | Функция |
|------|----------|
| **BEEPER** | Включить зуммер для обнаружения потерянного самолета |
| **BLACKBOX** | Запуск/остановка регистрации в Blackbox |
| **FAILSAFE** | Вручную активировать ступень безопасности 2 (выключатель паники) |
| **zz30zzz** | Переключить отображение OSD |
| **TELEMETRY** | Включить/выключить вывод телеметрии |

## Заметки об орнитоптере

- Режим **INDEPENDENT** уникален для OrniFlight —, он позволяет отображать сервоприводы для каждого крыла для асимметричной тяги и дифференциального управления крылом.
- Режим **GLIDE** удерживает крылья в нейтральном положении, что полезно для парения в условиях высоких температур и энергоэффективного спуска.
- Переключение **PROFILE** позволяет изменять параметры ONDAS в полете для различных условий полета (например, крейсерский режим или агрессивное маневрирование)
