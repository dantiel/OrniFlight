Экранное меню (OSD)

OrniFlight включает встроенный OSD (экранное меню), использующий микросхему MAX7456 или AT7456E. Zzz14zzz накладывает данные полета на ваш видеопоток FPV.

Поддерживаемые элементы

Настройте элементы на вкладке OSD конфигуратора OrniFlight. Перетаскивайте элементы, чтобы расположить их на экране.

Данные о полете

Элемент Дисплеи
Напряжение батареи Напряжение основной батареи (например, 14,8 В)
Среднее напряжение ячейки Напряжение на ячейку (например, 3,7 В)
Текущий розыгрыш Усилители мгновенного действия
мАч нарисовано Совокупная потребляемая мощность
RSSI Уровень сигнала от приемника
Режим полета Текущий режим (INDEPENDENT, GLIDE и т. д.)
Положение дроссельной заслонки Текущий процент дроссельной заслонки
Таймер Время полета/время на вооружении
Название ремесла OrniFlight название корабля

Специально для орнитоптера

Элемент Дисплеи
Частота хлопаний Текущая частота хода крыла в Гц
ONDAS Профиль Номер активного профиля полета (1-3)
Cadence Фаза Текущее смещение фазы модуляции
Угол сервопривода Положение сервопривода крыла

Управление шрифтами

В OSD используется символьная система отображения. Вкладка OSD конфигуратора OrniFlight включает в себя Диспетчер шрифтов для загрузки пользовательских шрифтов и глифов.

CLI Настройки

set osd_units = METRIC set osd_warn_bitmask = 270335 # Warning flag bitmask set osd_tim1 = 2560 # Timer 1 source set osd_tim2 = 2561 # Timer 2 source

Аппаратное обеспечение

В настоящее время поддерживается чип OSD: AT7456E (находится на OMNIBUSF4 и совместимых платах). MAX7456 совместим и определяется автоматически.
