Приемник (RX)

Приемник (RX)

OrniFlight поддерживает несколько протоколов приемника для радиоуправления вашим орнитоптером.

Поддерживаемые протоколы

Протокол Тип Заметки
CRSF (Перекрестный огонь) Серийный Низкая задержка, телеметрия, рекомендуется
SBUS Серийный Инвертированный, нужен инвертор на F4
IBUS (FlySky) Серийный Неперевернутый, прямой UART
PPM Однопроводной аналог 8-канальный, устаревший, не рекомендуется
SPEKTRUM Серийный 1024/2048, привязать через CLI
FPORT Серийный FrSky, сочетает в себе RX+телеметрию
GHST (Призрак) Серийный ImmersionRC, низкая задержка

Серийная конфигурация RX

  1. Подключите приемник к свободному контакту UART RX.
  2. В Конфигураторе → Порты: установите для UART значение Serial RX.
  3. В Конфигураторе → Конфигурация: выберите протокол.
  4. Для SBUS на F4: включите set sbus_inversion = ON

CLI Быстрая настройка

feature RX_SERIAL set serialrx_provider = CRSF set serialrx_inverted = OFF set serialrx_halfduplex = OFF save

Отказоустойчивый

Настройте отказоустойчивость приемника так, чтобы при потере сигнала приемник выдавал отсутствие импульсов. Контроллер полета обнаружит это и активирует собственную процедуру обеспечения безопасности. См. Failsafe для настройки уровня FC.
