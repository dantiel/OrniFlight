# Элементы управления

OrniFlight использует стандартное картографирование RC с расширениями, специфичными для орнитоптеров.

## Карты палочек

| Палка | Ось | Первичный эффект |
|-------|------|---------------|
| Дроссельная заслонка (слева, вертикально) | Дроссель | Амплитуда взмахов/тяга |
| Отклонение от курса (слева, горизонтально) | рыскание | Дифференциальная тяга крыла при повороте |
| Шаг (справа, вертикально) | Питч | Наклон вперед/назад |
| Ролл (правый, горизонтальный) | Ролл | Левый/правый берег |

## Режимы полета

| Режим | Поведение палки |
|------|---------------|
| **ACRO** | Стики управления угловой скоростью — нет автоматического уровня |
| **ANGLE** | Угол управления стиками — автоматически выравнивается при отпускании |
| **HORIZON** | ANGLE около центра, ACRO при полном отклонении |

ACRO рекомендуется опытным пилотам. ANGLE хорош для первых полетов и термического парения.

## Элементы управления, специфичные для орнитоптеров

### режим INDEPENDENT

Когда режим INDEPENDENT активен, каждый сервопривод крыла реагирует независимо:
- **Левый джойстик** → сервоприводы левого крыла
- **Правый джойстик** → сервоприводы правого крыла
- Обеспечивает асимметричное взмахивание крыльями для агрессивных маневров.

### режим GLIDE

Режим GLIDE фиксирует обе створки в горизонтальном положении. Орнитоптер становится планером:
- **Дроссель** не влияет на положение крыла.
- **Тангаж/крен/рыскание** по-прежнему влияют на рулевые поверхности хвоста (если есть)

### Переключение профиля

Переключение профиля в полете через канал AUX позволяет изменять параметры PID/ONDAS прямо в полете:
- **Профиль 1**: стандартные настройки круиза.
- **Профиль 2**: настройки высокой гибкости.
- **Профиль 3**: настройки эффективности/скольжения.

## Цены

Настройте тарифы на вкладке **PID Tuning**. Для орнитоптеров начните с консервативных скоростей —, динамика взмахов усиливается управляющими воздействиями:
- RC Скорость: 0.80–1.00
- Суперрейт: 0,60–0,70
- Экспо: 0.20–0.40
