RSSI

RSSI (Индикатор мощности принимаемого сигнала) показывает качество вашей радиосвязи. OrniFlight может получать RSSI из аналогового входа, данных последовательного приемника или протокола RSSI.

RSSI Исходники

Источник Подключение Конфигурация
Последовательный протокол Нет (по последовательному проводу RX) CRSF, GHST — автомат
Канал AUX Нет (TX отправляет RSSI в качестве канала) set rssi_channel = 8
Аналоговый ADC RSSI панель на FC → Ресивер RSSI выход set rssi_adc_channel = 1

Конфигурация

Серийный номер RSSI (CRSF/GHST/SBUS)

set rssi_src_frame_errors = OFF set rssi_scale = 100 set rssi_offset = 0

RSSI передается автоматически по последовательным протоколам —, дополнительная проводка не требуется.

Аналоговый RSSI

Подключите выход приемника RSSI → RSSI к контроллеру полета:

set rssi_adc_channel = 1 # Use ADC channel 1 set rssi_scale = 100 # Scale to 0-100% set rssi_offset = 0

AUX Канал RSSI

Настройте передатчик для отправки RSSI по определенному каналу, а затем:

set rssi_channel = 12 # Aux channel number set rssi_scale = 100 set rssi_offset = 0

Дисплей

RSSI отображается в OSD и может быть передан с помощью телеметрии на вашу радиостанцию. Настройте пороги предупреждений:

set osd_rssi_alarm = 20 # Warning at 20% RSSI

Диапазон орнитоптеров

Для орнитоптеров RSSI имеет решающее значение. Взмахи крыльев — создают динамические интерференционные картины RF. Контролируйте RSSI во время первых испытательных полетов, чтобы проверить надежность работы связи во всех положениях крыла.
