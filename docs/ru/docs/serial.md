# последовательные порты

OrniFlight использует последовательные порты для связи с периферийными устройствами: приемниками, GPS, телеметрией, управлением VTX, ведением журнала Blackbox и MSP (подключение к конфигуратору).

## Типы последовательных портов

| Тип | Описание | Лучшее для |
|------|------------|----------|
| **VCP** | USB Виртуальный COM Порт — прямое соединение USB с процессором | Конфигуратор (MSP) |
| **UART** | Аппаратные контакты TX/RX с аппаратным обнаружением сигнала | RX, GPS, Телеметрия, VTX, Черный ящик |
| **SoftSerial** | Программно-управляемый последовательный порт на любой паре контактов | Низкая пропускная способность: только телеметрия |

VCP не использует физический UART —, он всегда доступен для Конфигуратора.

## Назначение порта

В конфигураторе OrniFlight перейдите на вкладку **Порты** для назначения функций:

| Функция | Типичный UART | Заметки |
|----------|-------------|-------|
| Серийный RX | UART1 или UART3 | SBUS, CRSF, IBUS и т. д. |
| GPS | UART3 или UART6 | 57600 или 115200 бод |
| Телеметрия | Любой значок TX | SmartPort, HoTT, IBUS |
| VTX (Бродяга/SmartAudio) | Любой значок TX | Однопроводной |
| Черный ящик | Любой значок TX | OpenLog или встроенная вспышка |
| MSP | ззз45ззз (ззз46ззз) | Подключение конфигуратора |

## OMNIBUSF4 Сопоставление портов

| UART | Булавки | Типичное использование |
|------|------|------------|
| VCP | USB | MSP (Конфигуратор) |
| UART1 | TX1/RX1 | Серийный RX |
| UART3 | TX3/RX3 | GPS или Телеметрия |
| UART6 | TX6/RX6 | Бесплатно / Черный ящик / VTX |

## SoftSerial

SoftSerial доступен, но имеет ограниченную пропускную способность. Подходит только для низкоскоростной телеметрии (например, 9600 бод SmartPort). Не рекомендуется для серийных RX или GPS.
