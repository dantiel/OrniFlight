# Поддерживаемое оборудование

OrniFlight работает на стандартных контроллерах полета STM32F3/F4/F7. Базовая линия: **STM32F3** —, любая цель F3 с таймерами, поддерживающими сервопривод, будет летать.

## Контроллеры полета

| Совет | MCU | IMU | Флэш | Ресивер | Статус |
|-------|-----|-----|-------|----------|--------|
| **TINYFISH** | STM32F303 | MPU6000 (SPI) | 256 KB | FrSky D8 (встроенный) | ✅ Первичная |
| **OMNIBUSF4** | STM32F405 | ззз52ззз (ззз53ззз) | 1 MB + 16 MB SPI | — | ✅ Поддерживается |

### TINYFISH — Самая легкая мишень OrniFlight

Zzz31zzz, разработанный Fishpepper, представляет собой идеальный контроллер полета для орнитоптера: легкий, на базе F3, оснащенный **интегрированным приемником FrSky D8** на борту. Никаких внешних RX, никакой дополнительной проводки —, только питание, сервоприводы и полет.

- **MCU**: STM32F303CCT6 @ 72 МГц
- **Гироскоп**: MPU6000 (SPI, поддерживает частоту 8 кГц)
- **Вспышка**: 256 KB встроенная
- **RAM**: 40 KB
- **Приёмник**: встроенный FrSky D8 (SBUS внутренне перенаправлен на UART2)
- **UART**: VCP + 2 аппаратных UART (UART1 бесплатно для дополнения GPS/CRSF)
- **Вход**: 2-4S LiPo (прямое питание сервопривода)
- **Вес**: ~2,5 г.

TINYFISH доказывает, что превосходное управление взмахами не требует F7. Zzz73zzz управляет полным конвейером ONDAS —, 10 каналами модуляции, трапециевидным крылом ODE, 4 профилями полета — в пределах 256 KB.

### OMNIBUSF4 — Доступная рабочая лошадка

Классическая мишень F4. Дешевый, вездесущий, полнофункциональный с OSD и обширной флэш-памятью SPI для ведения журналов Blackbox. Идеально подходит для разработки и более крупных сборок.

- **MCU**: STM32F405RGT6 @ 168 МГц
- **Гироскоп**: MPU6000 (SPI, поддерживает частоту 8 кГц)
- **Флэш-память**: 1 встроенная память MB + 16 MB SPI (Blackbox)
- **RAM**: 192 KB
- **OSD**: AT7456E (совместимо с MAX7456)
- **UART**: VCP + 5 аппаратных UART.
- **Барометр**: BMP280 (некоторые варианты)
- **Вход**: 2-6S LiPo

## Анатомия орнитоптера

### Крыльевые сервоприводы

OrniFlight управляет взмахами с помощью сервоприводов PWM. Ключевые характеристики:

| Параметр | Типичный диапазон |
|-----------|--------------|
| Ширина импульса | 500–2500 µs |
| Центр | 1500 ззз11ззз |
| Частота | 50–330 Гц |
| Угол хода | ±15–45° |

Для высокопроизводительных орнитоптеров рекомендуются цифровые сервоприводы с частотой обновления 330 Гц. Аналоговые сервоприводы работают на частоте 50 Гц, но имеют меньшую точность.

### Приемник

Поддерживается любой протокол последовательного приемника. CRSF (TBS Crossfire / ExpressLRS) рекомендуется для:
- Низкая задержка (критична для управления взмахами)
- Встроенная телеметрия
- RSSI по протоколу (без дополнительной проводки)

### Батарея

- **2S (7,4 В)**: Маленькие орнитоптеры с прямым сервоприводом.
- **3S (11,1 В)**: средние орнитоптеры, для сервоприводов требуется BEC.
- **4S (14,8 В)**: большие орнитоптеры, рекомендуется внешний BEC.

## Поддерживаемые периферийные устройства

| Периферийное | Через | Заметки |
|-----------|-----|-------|
| GPS | UART | Ublox M8N или совместимый |
| VTX | UART TX | Бродяга, SmartAudio |
| Камера | — | Любая аналоговая камера FPV |
| Зуммер | BUZZ панель | Активный зуммер 5 В |
| LED Полоса | LED панель | WS2812 / SK6812 |
| OpenLog | UART TX | Регистрация в «черном ящике» |
| Bluetooth | UART | MSP passthrough для мобильной настройки |

## Будущие цели

OrniFlight предназначен для поддержки дополнительных целей STM32F4/F7, где доступны достаточные ресурсы UART и таймера для управления сервоприводом. Вклады приветствуются.
