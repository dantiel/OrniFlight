# Микшер

Микшер преобразует сигналы контроллера полета (крен, тангаж, рыскание, газ) в сервосигналы для вашего орнитоптера.

## Орнитоптерный миксер

OrniFlight расширяет систему микшера Betaflight конфигурациями, специфичными для орнитоптеров. Миксер имеет:

- **Сервоприводы крыльев**: преобразование выходного сигнала PID в модуляцию хода крыла.
- **Хвостовые сервоприводы** (опция): управление рулями высоты и рулями направления.

## Типы микшеров

| Миксер | Вариант использования |
|-------|----------|
| **ORNITHOPTER** | Стандартный двухкрылый орнитоптер с двумя сервоприводами крыльев |
| **ORNITHOPTER_4S** | 4-х сервоприводной орнитоптер (независимое управление левым/правым крылом) |
| **ORNITHOPTER_TAIL** | Двойное крыло + хвостовой руль высоты + руль направления |

## Конфигурация сервопривода

Настраивается на вкладке **Сервоприводы** или через CLI:

```
smix reverse 0 2 r       # Reverse servo 2
smix 0 0 0 100 0 0 100   # Servo 0: roll mixing
smix 1 1 1 100 0 0 100   # Servo 1: pitch mixing
```

## ONDAS Интеграция

Микшер работает совместно с ONDAS (нелинейной динамической аэродинамической системой Ornithopter):

- **Дроссель** → устанавливает базовую амплитуду взмахов
- **ONDA Cadence** → сдвигает окно модуляции внутри каждого штриха.
- **ONDA Ferocity** → изменяет форму волны штриха (синусоидальная, ↔, трапециевидная)
- **ONDA Balance** → коррекция симметрии левого/правого крыла

Подробную теорию ONDAS можно найти в [ONDAS Wiki](../wiki/ondas.html).

## CLI Настройки

```
mixer = ORNITHOPTER
set servo_pwm_rate = 330     # Servo update frequency
set servo_center_pulse = 1500
set flap_spread = 20         # Wing angle amplitude in degrees
```
