# Видеопередатчик (VTX)

OrniFlight поддерживает управление VTX для орнитоптеров FPV. Модули VTX можно настроить с помощью конфигуратора OrniFlight, MSP или CLI или CLI, устанавливая диапазон —, канал, уровень мощности и режим ямы.

## Поддерживаемые протоколы

1. **IRC Tramp** — Обычно используется на небольших модулях VTX, идеально подходит для легких орнитоптеров FPV.
2. **TBS SmartAudio** — Цифровой протокол с поддержкой режима ямы
3. **RTC6705** — Прямое управление SPI на платах со встроенным VTX (например, SPRACINGF3NEO)

## Конфигурация

Настройки VTX управляются через вкладку **VTX** в конфигураторе OrniFlight или через CLI:

```
set vtx_band = 5           # Raceband
set vtx_channel = 1        # 5658 MHz
set vtx_power = 2          # 200mW
set vtx_low_power_disarm = ON  # Lower power when disarmed
set vtx_pit_mode_freq = 0  # Pit mode frequency (0 = disabled)
```

## Последовательный порт

Для управления VTX требуется специальный контакт UART TX. Настройте порт на вкладке **Порты** с помощью периферийного устройства `IRC Tramp` или `TBS SmartAudio`.

## FPV Соображения об орнитоптерах

- Вес имеет решающее значение. — выбирайте легкие модули VTX (Tramp Nano, Eachine Nano)
- Крепление антенны: обеспечить зазор от машущих крыльев.
- Фильтрация мощности: подключите питание VTX после фильтра LC, чтобы избежать сервошума в видео.
- Режим Pit рекомендуется для стендовых испытаний, чтобы избежать перегрева небольших модулей VTX.
