# Отказоустойчивый

OrniFlight имеет двухступенчатую отказоустойчивую систему для защиты вашего орнитоптера в случае потери сигнала приемника.

## Двухступенчатая система

### Обнаружена потеря сигнала на этапе 1 —

Срабатывает, когда:
- Любой канал полета имеет недопустимую длину импульса.
- Приемник сообщает о отказоустойчивом режиме
- Нет сигнала от приемника в течение заданного времени.

**Действие**: Все каналы переключаются на резервные значения (настраиваются через `rxfail`). Короткое окно восстановления начинается —. Если сигнал возвращается, возобновляется нормальный полет.

### Этап 2 — Время охраны истекло

Вводится, когда стадия 1 продолжается дольше, чем `failsafe_delay` (по умолчанию: 400 мс), И корабль поставлен на охрану.

**Процедуры** (настраиваются через `failsafe_procedure`):

| Процедура | Поведение |
|-----------|----------|
| **DROP** | Немедленно обезвредить —, крылья останавливаются, самолет снижается |
| **LAND** | Режим планирования —, крылья зафиксированы в горизонтальном положении, контролируемое снижение |

**LAND** — рекомендуемая процедура для орнитоптеров. — — она удерживает крылья в нейтральном положении для планирующего снижения, давая время для восстановления сигнала.

## CLI Настройки

```
set failsafe_delay = 4         # Guard time in 0.1s (4 = 400ms)
set failsafe_procedure = LAND  # DROP or LAND
set failsafe_throttle = 1000   # Fallback throttle (low)
set failsafe_switch_mode = STAGE1  # Transmitter switch behavior
```

## Отказоустойчивость приемника

Также настройте отказоустойчивость вашего приемника на вывод **отсутствия импульсов** при потере сигнала. Это позволяет диспетчеру полета обнаружить потерю и активировать этап 1.

## Тестирование

Испытание отказоустойчивости **с отсоединенным рычажным механизмом** на стенде:
1. Назначьте переключатель режиму FAILSAFE.
2. Вооружить поделку
3. Переключите переключатель →, соблюдая процедуру обеспечения безопасности.
4. Убедитесь, что поведение сервопривода соответствует ожиданиям.
