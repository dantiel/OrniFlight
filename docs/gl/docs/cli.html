CLI Referencia

A interface de liña de comandos de OrniFlight (CLI) ofrece acceso total a todas as opcións. Acceda a través da pestana CLI no Configurador de OrniFlight ou mediante un terminal en serie a 115200 baudios.

Comandos básicos

Comando Descrición
help Mostrar todos os comandos
status Mostrar o estado do sistema
version Mostrar a versión do firmware
defaults Restablecer todos os axustes aos valores predeterminados
save Garda a configuración e reinicia
exit Saír de CLI (reiniciar sen gardar)
diff Mostrar a configuración modificada (útil para compartir configuracións)
dump Mostrar todos os axustes
dump all Mostrar todos os axustes incluídos os valores predeterminados do hardware
