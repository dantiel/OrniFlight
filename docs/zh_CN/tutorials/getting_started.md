# 开始使用

欢迎来到OrniFlight！本指南将引导您完成扑翼机飞行控制器的初始设置。

## 你需要什么

- **OrniFlight 配置器** — 从 [orniflight.org](https://orniflight.org) 下载
- **USB 电缆** — 将飞行控制器连接到计算机
- **扑翼机** 具有：
  - 支持的飞行控制器（OMNIBUSF4、TINYFISH）
  - 机翼驱动伺服系统
  - 接收器绑定到您的发射器
  - 电池（2S–4S LiPo）

## 快速入门

### 1. 闪存固件

1. 打开 **OrniFlight 配置器**
2. 转到 **固件刷新器** 选项卡
3. 选择您的开发板目标（OMNIBUSF4 或 TINYFISH）
4.选择最新稳定版本
5. 单击“**加载固件**”，然后单击“**刷新固件**”

### 2. 初始配置

闪烁后，配置器将提示您应用自定义默认值。 **始终接受。**

### 3. 接收器设置

1. 转到 **端口** 选项卡 → 将正确的 UART 设置为 `Serial RX`
2. 转到 **配置** 选项卡 → 选择您的接收器协议（CRSF、SBUS 等）
3. 转到 **接收器** 选项卡 → 验证摇杆移动是否与预期通道匹配
4.设置通道端点：1000–2000，中心1500

### 4. 伺服设置

1. 转到**舵机**选项卡
2. 验证伺服映射与扑翼机的机翼配置相匹配
3. 如果需要测试舵机方向 — 反向
4. 设置中心位置（机翼水平 = 1500）

### 5. 模式设置

1. 转到 **模式** 选项卡
2. 将 ARM 分配给 AUX 开关
3. 根据需要指定飞行模式（ANGLE / ACRO / HORIZON）
4. 将 INDEPENDENT 和 GLIDE 分配给备用交换机
5.配置BEEPER进行丢失模型定位

### 6. 第一次飞行

1. **断开机翼连杆进行台架测试**
2. 启动并验证舵机运动方向
3.检查油门响应
4. 首次实际飞行：使用ANGLE模式，资费低
5. 将鼠标悬停在视线高度，根据需要进行修剪
