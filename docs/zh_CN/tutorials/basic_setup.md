# 基本设置

> *配置您的扑翼机进行首次飞行。*

## 飞行前检查清单

首先：

- [ ] 飞行控制器闪烁 OrniFlight
- [ ] 接收器绑定到发射器
- [ ] 舵机连接到正确的 PWM 输出
- [ ] 电池已连接（机翼固定！）

## 接收器设置

### CRSF（推荐）

1. **端口选项卡**：将 UART（例如 UART1）设置为“串行 RX”
2. **配置选项卡**：接收器模式=“基于串行的接收器”，提供者=“CRSF”
3. 重新启动电源，验证通道输入在接收器选项卡中移动

### SBUS / 其他

相同的过程 — 在“配置”选项卡中选择适当的协议。

## 伺服映射

在**伺服选项卡**中：

|伺服|功能|违约率|
|--------|----------|-------------|
|伺服0 |左翼| 250 赫兹 |
|伺服1 |右翼 | 250 赫兹 |
|伺服2 |顶/舵 | 50赫兹|

调整最小/最大/中间以匹配您的伺服器范围。使用“覆盖”进行测试以验证方向。

## 飞行模式选择

在 **模式选项卡**：

1. **ARM**：分配给开关（安全！）
2. **ORNITHOPTER INDEPENDENT** 或 **ORNITHOPTER GLIDE**：选择您的主要飞行模式
3. **ORNITHOPTER PROFILE**：可选 — 分配用于飞行中的配置文件切换

## ONDAS 第一次调音

转到**高级 → ONDAS 子选项卡**：

1. **Cadence 增益**：从 50（中）开始。这是最重要的参数。
2. **Ferocity D 增益**：从 30 开始。这是您的主要稳定性。
3. **Ferocity P 增益**：横滚/俯仰从 20 开始，偏航从 0 开始。
4. **Balance 增益**：0（居中）。

连接电池，**牢固固定扑翼机**，然后 ARM。观察舵机运动 — 应该是平滑的、正弦扑动的。

## 第一次飞行

1. 首先将其轻轻抛入风中
2.使用GLIDE模式，获得自然翱翔的感觉
3. 当您想要直接频率控制时，请使用 INDEPENDENT 模式
4.着陆，调整ONDAS，重复
