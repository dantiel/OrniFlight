安装

如何在飞控上安装 OrniFlight 固件。

先决条件

  • OrniFlight 配置器（最新版本）
  • USB数据线（非充电专用）
  • 支持的飞控板

支持的主板

董事会 目标 闪光 笔记
OMNIBUSF4 OMNIBUSF4 16MB STM32F405、MPU6000、OSD
TINYFISH TINYFISH 256KB STM32F411, MPU6000

闪烁步骤

1. 进入 DFU/Bootloader 模式

OMNIBUSF4：连接 USB 时按住 BOOT 按钮。红色 LED 保持稳定 — 您处于 DFU 模式。

TINYFISH：连接 USB 时按住 BOOT 按钮。

2. 通过配置器刷新

  1. 打开 OrniFlight 配置器
  2. 转到 固件刷新器 选项卡
  3. 从下拉列表中选择您的目标 4.选择固件版本（推荐最新稳定版本） 5.点击加载固件（在线）或选择本地hex文件
  4. 单击刷新固件 7.等待“编程：成功”

3. 第一次连接

闪烁后： 1. 断开并重新连接 USB（无 BOOT 按钮） 2. 配置器应自动连接 3.接受“应用自定义默认值”提示 4. 在“设置”选项卡上验证主板信息

故障排除

没有 DFU 端口

macOS/Linux：DFU 应该会自动出现。如果没有： 呜呜呜

Windows：安装 Zadig 以替换 STM32 DFU 驱动程序： 1. 奔跑扎迪格 2. 选项 → 列出所有设备 3. 选择“STM32 BOOTLOADER” 4. 将驱动程序替换为“WinUSB”

闪存失败

  • 尝试使用不同的 USB 电缆（可传输数据，而非仅充电）
  • 尝试不同的 USB 端口（直接，而不是集线器）
  • 在整个闪光过程中按住 BOOT 按钮
  • OMNIBUSF4：可能需要全芯片擦除 — 检查“全芯片擦除”选项

配置器无法连接

  • 验证 USB 电缆是否具有数据能力
  • 检查板是否处于 DFU 模式（LED 闪烁 = 正常模式）
  • 重新启动配置器
  • 尝试不同的 USB 端口
