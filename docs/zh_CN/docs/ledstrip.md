# LED 地带

OrniFlight 支持可寻址 WS2812/SK6812 LED 条，用于状态指示和视觉反馈。

## 配置

LED 条带在 OrniFlight 配置器的 **LED Strip** 选项卡中进行配置。每个 LED 的位置、颜色和功能都可以单独设置。

## 函数

|功能|视觉效果|
|----------|--------------|
|电池指示器|颜色渐变从绿色 → 黄色 → 红色 |
| RSSI |信号强度显示|
|手臂状态|布防/撤防颜色变化 |
|飞行模式 |特定于模式的颜色 |
|警告|低电量时的闪烁模式，故障安全 |
|扑动指示器|当前扑动频率下的脉冲|
|推力方向|指示横滚/俯仰/偏航输出的颜色偏移 |
| GPS |卫星锁定和返航方向 |

## 硬件

- WS2812 或 SK6812 RGB LED
- 连接到飞行控制器上的 **LED** 焊盘/引脚
- 从 BEC 为 LED 供电（不要使用 5V 从 3.3V — 供电）
- 对于长条（>8 个 LED），将 5V 电源直接连接到电池垫，而不是通过 FC

## 扑翼机使用

**扑动指示器**是 OrniFlight — LED 所独有的，其脉冲与机翼冲程频率同步，以视觉方式表示扑动节奏，并帮助调整 ONDAS 节奏参数。
