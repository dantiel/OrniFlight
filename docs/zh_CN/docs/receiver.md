# 接收器 (RX)

OrniFlight 支持多种接收器协议，用于扑翼机的无线电控制。

## 支持的协议

|协议|类型 |笔记|
|----------|------|--------|
| **CRSF**（交叉火力）|连续剧 |低延迟，遥测，推荐 |
| **SBUS** |连续剧 |倒置，F4 上需要逆变器 |
| **IBUS** (FlySky) |连续剧 |非倒相，直接 UART |
| **PPM** |单线模拟| 8ch，传统，不推荐 |
| **SPEKTRUM** |连续剧 | 1024/2048，通过 CLI 绑定 |
| **FPORT** |连续剧 | FrSky，结合了 RX+遥测 |
| **GHST**（幽灵）|连续剧 | ImmersionRC，低延迟 |

## 串口 RX 配置

1. 将接收器连接到空闲的 UART RX 引脚
2. 在配置器 → **端口** 中：将 UART 设置为 `Serial RX`
3. 在配置器 → **配置**中：选择协议
4. 对于 F4 上的 SBUS：启用 `set sbus_inversion = ON`

## 故障保护

配置接收器故障保护，以便接收器在信号丢失时**不输出脉冲**。然后，飞行控制器将检测到这一点并激活其自己的故障保护程序。请参阅 [故障保护](failsafe.html) 了解 FC 级别的配置。
