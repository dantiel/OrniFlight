飞行模式

通过发射器上的 AUX 开关切换模式。每种模式都可以在 OrniFlight 配置器的 模式 选项卡中分配给特定的 AUX 通道范围。

标准模式

模式 功能  
ARM 启用飞行控制（电机/伺服系统激活）  
ANGLE 当操纵杆居中时自动调平 — 飞行器返回水平  
HORIZON 混合 — 角度模式靠近中心，全摇杆 Acro
ACRO 默认 — 无自动电平，纯速率控制  
AIRMODE 保持 PID 循环处于零油门状态以获得完全权限  

OrniFlight-特定模式

ID 模式 功能
50 50 INDEPENDENT 独立机翼控制 — 每个机翼响应其自己的伺服通道
51 51 GLIDE 滑翔模式 — 翅膀锁定在水平位置以便翱翔
52 52 PROFILE 飞行模式选择 — 在 3 个 PID/ONDAS 模式之间切换

实用模式

模式 功能
BEEPER 激活蜂鸣器以定位丢失的飞机
BLACKBOX 启动/停止 Blackbox 日志记录
FAILSAFE 手动触发故障安全阶段 2（紧急开关）
OSD 切换 OSD 显示
TELEMETRY 启用/禁用遥测输出

扑翼机笔记

  • INDEPENDENT 模式是 OrniFlight — 所独有的，它支持每翼伺服映射，以实现不对称推力和差动翼控制
  • GLIDE 模式将机翼保持在中立位置，对于热腾腾和节能下降非常有用
  • PROFILE 切换允许在飞行中 ONDAS 参数更改以适应不同的飞行条件（例如，巡航与激进的机动）
