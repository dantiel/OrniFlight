安全

安全

飞行前检查清单

  1. 机翼：确保机翼安装牢固且连杆完好
  2. 电池：已充满电、正确固定、电池数正确
  3. 控制：验证配置器接收器选项卡中的摇杆响应
  4. 故障安全：飞行前在台上测试（参见故障安全）
  5. 布防开关：配置和测试 — 永远不要单独依赖摇杆布防
  6. 发射区域：没有人员、障碍物和头顶障碍物

手臂安全

OrniFlight 在布防前使用多个安全装置：

  • 油门低：油门必须最小
  • 等级：工艺必须相当水平
  • RX 信号：需要有效的接收器信号
  • CPU 负载：系统不得过载
  • 校准：必须校准加速度计和陀螺仪

飞行安全

  • 在视线范围内飞行
  • 与人和动物保持安全距离
  • 在警告阈值之前监控电池电压 — 着陆
  • 在 FPV 中：始终与观察员一起飞行
  • 风：扑翼机可能对风敏感 — 知道你的极限

紧急程序

情况 行动
失去方向 切换到 INDEPENDENT 模式，中心摇杆
信号丢失 故障保护将自动着陆（如果配置了 LAND 程序）
机翼损伤 立即解除武装 — 翅膀停止
鸟击 解除武装，在重新武装之前评估损失
电池电量低 立即着陆 — 扑翼机没有自转

扑翼机特定风险

  • 夹伤危险：拍打翅膀可能会造成伤害 — 武装时请保持双手远离
  • 连杆故障：飞行前检查所有推杆和球窝接头
  • Resonance：某些扑动频率可能会激发机身共振 — 调整 ONDAS 扫描以避免
  • 滑翔锁定：如果机翼伺服系统在非中立位置发生故障，则不可能进行受控着陆 — 测试伺服系统故障安全位置
