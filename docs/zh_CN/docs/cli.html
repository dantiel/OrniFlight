CLI 参考

OrniFlight 的命令行界面 (CLI) 提供对所有设置的完全访问。通过 OrniFlight 配置器中的 CLI 选项卡或通过 115200 波特率的串行终端进行访问。

基本命令

命令 描述
help 显示所有命令
status 显示系统状态
version 显示固件版本
defaults 将所有设置重置为默认值
save 保存设置并重新启动
exit 退出 CLI（重新启动而不保存）
diff 显示更改的设置（对于共享配置很有用）
dump 显示所有设置
dump all 显示所有设置，包括硬件默认值
