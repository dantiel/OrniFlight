# 屏幕显示 (OSD)

OrniFlight 包括使用 MAX7456 或 AT7456E 芯片的内置 OSD（屏幕显示）。 OSD 将航班数据叠加到您的 FPV 视频源上。

## 支持的元素

在 OrniFlight 配置器的 **OSD** 选项卡中配置元素。拖放元素以将其放置在屏幕上。

### 航班数据

|元素|显示器|
|---------|----------|
|电池电压|主电池电压（如14.8V）|
|平均电池电压|每节电池电压（例如 3.7V）|
|当前消耗|瞬时放大器|
| mAh 绘制 |累计消耗容量|
| RSSI |接收器的信号强度|
|飞行模式 |当前模式（INDEPENDENT、GLIDE 等）|
|油门位置|当前油门百分比|
|定时器|飞行时间/武装时间|
|工艺名称| OrniFlight 工艺名称 |

### 扑翼机专用

|元素|显示器|
|----------|----------|
|扑动频率|当前机翼冲程频率（以 Hz 为单位）|
| ONDAS 简介 |有效航班资料编号 (1-3) |
| Cadence 阶段 |电流调制相位偏移|
|伺服角度|机翼舵机位置|

## 字体管理

OSD 使用基于字符的显示系统。 OrniFlight 配置器的 **OSD** 选项卡包括一个 **字体管理器**，用于上传自定义字体和字形。
