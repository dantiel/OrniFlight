# 蜂鸣器

OrniFlight 支持有源蜂鸣器，用于声音状态指示和丢失模型定位。

## 函数

- **布防/撤防** — 不同的音调
- **低电量** — 重复警告蜂鸣声
- **故障安全** — SOS 模式
- **丢失模型** — 通过开关连续发出蜂鸣声
- **GPS 修复** — 卫星锁定确认音
- **校准** 陀螺仪/加速校准期间发出 — 蜂鸣声模式
- **RX 信号丢失** — 接收器连接断开时发出警告

## 硬件

- 将 5V 有源蜂鸣器（不是无源压电）连接到 **BUZZ-** 和 **BUZZ+** 焊盘
- 蜂鸣器由 FC — 上的晶体管驱动，标准蜂鸣器无需外部驱动器

## 扑翼机安全

蜂鸣器对于可能降落在高高的草丛或树叶中的大型扑翼机特别有用。在瞬时开关上配置 BEEPER 模式，以便在需要时快速激活。
