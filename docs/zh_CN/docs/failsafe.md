# 故障保护

OrniFlight 具有两级故障安全系统，可在接收器信号丢失时保护您的扑翼机。

## 两级系统

### 第 1 阶段 — 检测到信号丢失

触发时间：
- 任何飞行通道的脉冲长度无效
- 接收器报告故障安全模式
- 在配置的时间内没有来自接收器的信号

**操作**：所有通道切换到后备值（通过 `rxfail` 配置）。如果信号返回，则短暂的恢复窗口将开始 —，恢复正常飞行。

### 第 2 阶段 — 守卫时间已结束

当阶段 1 持续时间超过 `failsafe_delay`（默认值：400 毫秒）并且飞行器已布防时进入。

**程序**（可通过 `failsafe_procedure` 配置）：

|程序 |行为 |
|------------|----------|
| **DROP** |立即解除武装 — 机翼停止，飞机下降 |
| **LAND** |滑翔模式 — 机翼锁定水平，受控下降 |

**LAND** 是扑翼机的推荐程序 — 它将机翼保持在中立位置以进行滑翔下降，为信号恢复提供时间。

## 接收器故障保护

还可以将接收器的故障保护配置为在信号丢失时**不输出脉冲**。这使得飞行控制器能够检测到丢失并激活第 1 阶段。

## 测试

在工作台上测试故障安全**机翼连杆断开**：
1. 将 FAILSAFE 模式分配给交换机
2. 武装飞船
3. 切换开关 → 遵守故障安全程序
4. 验证伺服行为是否符合预期
