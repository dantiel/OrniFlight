# 混合器

混合器将飞行控制器输出（横滚、俯仰、偏航、油门）转换为扑翼机的伺服信号。

## 扑翼机混合器

OrniFlight 通过扑翼机特定配置扩展了 Betaflight 的混合器系统。搅拌机手柄：

- **机翼伺服系统**：将 PID 输出转换为机翼行程调制
- **尾部伺服系统**（可选）：控制升降舵/方向舵表面

## 混合器类型

|搅拌机|使用案例|
|--------|----------|
| **ORNITHOPTER** |带 2 个机翼舵机的标准双翼扑翼机 |
| **ORNITHOPTER_4S** | 4-伺服扑翼机（独立左/右翼控制）|
| **ORNITHOPTER_TAIL** |双翼+尾升降舵+方向舵|

## ONDAS 集成

该混合器与 ONDAS（扑翼机非线性动力空气动力系统）协同工作：

- **油门** → 设置基础扑动幅度
- **ONDA Cadence** → 在每个笔划内移动调制窗口
- **ONDA Ferocity** → 修改笔划波形形状（正弦 ↔ 梯形）
- **ONDA Balance** → 左/右翼对称校正

有关详细的 ONDAS 理论，请参阅 [ONDAS Wiki](../wiki/ondas.html)。
