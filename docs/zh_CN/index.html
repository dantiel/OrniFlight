宣言

新一代飞控

OrniFlight之所以存在，是因为扑翼在一个行程内控制推力、俯仰、滚转和偏航--这是一个螺旋桨无法比拟的表现力通道。

大自然在第一架四轴飞行器起飞前1.5亿年解决了扑翼飞行。每只麻雀、每只信天翁、每只蜂鸟的神经系统都带有飞行逻辑，这是PID控制器从未复制的。OrniFlight开辟了一个新的领域--推力是相位，稳定是节奏，飞机每次翅膀跳动都会呼吸。 ONDAS ，我们的振荡归一化动态自适应稳定，是根据扑翼空气动力学的第一原理建立的第一个控制理论。它调节翅膀节拍内的校正力—不是针对它，也不是尽管它，而是与它一起。此固件是免费软件，因为FLIGHT不属于任何公司。它在商品STM32F3硬件上运行，因为超凡飞行的工具应该比晚餐便宜。 OrniFlight继承了一种久经考验的架构，并将其推入了未知的空气中--一种新型的飞行控制器，专为从硅片上方的翅膀而设计。鸟儿们一直在等着我们赶上来。

ONDAS

振荡归一化动态自适应稳定

振荡归一化动态自适应稳定—第一个专为扑翼空气动力学构建的控制理论。

四PID假设连续推力。Ornithopter的推力是相位的—相同的冲动会产生不同的时刻，具体取决于它在何时施加。ONDAS使用节奏、凶猛、不对称、翘曲、锚定、共振、先见之明、espelho、saudade和SSFF （相位感知调制器的管弦乐队）来准确放置空气动力学可以使用的每个校正克。

功能

翅膀应得的一切

飞行配置
4个独立轮廓（ 0–3 ） ，可通过箱式模式在飞行中切换。每个都具有完整的ONDAS调谐、波形和气动弹性系数。
统一频率通道
单个RC通道，最小/最大Hz映射。在独立和滑翔飞行模式下工作相同—一个锅，两种状态。
GralhaAzul 机翼动力学
具有伺服限速、振幅映射、襟翼幅值和机翼原点几何形状的梯形波形生成—机翼-ODE核心。
10通道 ONDAS 调制
节奏定时， 3轴凶猛P/D ，平衡，翘曲，锚定，共振—每个轮廓，通过MSP实时可调。
MSP 配置器 (apiVersion 1.46)
全ONDAS调整GUI —所有19个配置文件字段，频率通道， GralhaAzul ，第2阶段增益。用于每时隙编辑的配置文件切换器。
GLIDE 与 INDEPENDENT 模式
两种飞行方式：滑翔（以油门为中心，自然飙升）和独立（通过RC通道直接襟翼频率）。BOX可选。

硬件

STM32F3/F4/F7 飞控

可在任何兼容Betaflight 4.0的STM32F3/F4/F7飞行控制器上运行，带有伺服定时器引脚。

目标 TINYFISH （ F3 ，集成FrSky RX ）、OMNIBUSF4、MATEKF405、KAKUTEF7……
舵机输出 最多4个可编程伺服通道， 50–400 Hz PWM
接收机 CRSF （ Crossfire/ExpressLRS ）、SBUS、Spektrum、SUMD -以及TINYFISH上的集成FrSky
闪存 256 KB (TINYFISH F3) / 1 MB (OMNIBUSF4)
内存 40 KB (TINYFISH F3) / 192 KB (OMNIBUSF4)
