# Servo-Effizienz

Eine kuratierte Auswahl getesteter Servos für Ornithopter.
**Effizienz** = Drehmoment / (Gewicht × Geschwindigkeit). **Eff/€ ★** = Effizienz pro Euro, skaliert mit &cuberoot;Drehmoment.
